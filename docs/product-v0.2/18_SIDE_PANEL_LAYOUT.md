## 1. 패널의 첫 화면

```text
┌──────────────────────────────────────────┐
│ YUTOPIA        [선택된 영상 B]    닫기   │
│ 영상 반응 상세 · 최신 시각/데이터 상태    │
├──────────────────────────────────────────┤
│ 영상/채널 제목과 분석 대상·기간           │
│                                          │
│ 반응 요약                                │
│ 긍정 ━━━━━  중립 ━━━  부정 ━━       │
│ 댓글 표본/미분류/제외·범위·출처           │
├──────────────────────────────────────────┤
│ 주요 쟁점 · 요약 브리핑                   │
│ ① 쟁점 A  ② 쟁점 B  ③ 쟁점 C             │
│                                          │
│ 상세 감성·시간 변화                      │
│ 근거와 검증 한계                         │
├──────────────────────────────────────────┤
│ 구독 확장: 장기 추세·여러 영상 비교      │
│ 저장/모니터링/보고서(추후)                │
└──────────────────────────────────────────┘
```

**모든 수치·차트는 데모용 합성 데이터로 시작합니다.** Chrome 패널 폭과 배치 위치는 브라우저가 관리하므로 고정 폭/고정 우측을 보장하지 않습니다.

## 2. 정보 우선순위

1. **선택 대상** — 영상인지 채널인지, ID·제목·소스 범위를 명확히.
2. **상태** — 결과 있음/부분/오래됨/데이터 없음/정책 차단.
3. **감성·주요 쟁점** — YUTOPIA의 분석 추정임을 표시.
4. **근거·표본** — 분석 기간·원시/분류 완료/제외·최신성.
5. **세부 도구** — 기간/채널 비교, 검토 이력, 구독 기능.
6. **관리 메뉴 제외** — 수집 Job 강제 조작·QA 역할 변경/데이터 강제 성공 없음.

## 3. 영상과 채널의 차이

- **VIDEO:** 해당 영상 1개의 댓글 반응·주제·시계열(가능할 때).
- **CHANNEL:** 선택/관측된 영상 집합을 대상으로 한 집계·비교. 선정 영상 수·조건·기간 필수.
- **고정:** 다른 썸네일 Hover는 패널을 바꾸지 않음; 사용자가 다른 더보기를 눌러야 전환.
- **비교:** 사용자의 구독 범위와 자료 사용권을 모두 충족한 결과만 보여줌.

## 4. 로그인·구독 UX

- **기본 사용:** 허용한 한도 내에서 상세의 핵심 내용 표시.
- **유료 확장:** 긴 기간·여러 영상/채널 비교, 저장·모니터링/보고서 등.
- **구독 문구:** 가격/기간 등 미결정 상품을 실제 가격으로 표시 금지.
- **정책 차단:** 자료가 제한된 경우 돈을 내면 무조건 분석할 수 있다고 주장하지 않음.

## 5. 수용 테스트

- [ ] Side Panel에 클릭한 영상/채널의 제목/ID가 정확히 보인다.
- [ ] 감성/쟁점·분모·시각·출처·불확실성을 확인 가능.
- [ ] 구독 제한은 상세 기능만 차단하며 실제 자료 권리를 우회하지 않음.
- [ ] 패널의 텍스트가 좁은 폭에서도 읽기 쉽다.
- [ ] 스크롤/키보드/스크린리더로 패널 내용에 접근 가능하다.
- [ ] 다른 Hover로 이미 열린 분석 대상이 갑자기 바뀌지 않는다.
- [ ] 정책/자료 부족 시 허위 차트·성공 고지가 없다.
