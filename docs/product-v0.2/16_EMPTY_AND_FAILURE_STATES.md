## 1. 동일한 '정보 없음'으로 합치지 않음

| 내부 상태 제안 | 고객에게 보일 문구 | 복구/행동 |
|---|---|---|
| `LOADING` | 반응 정보를 확인하고 있습니다 | 진행 중 표시 |
| `READY` | 관측 가능한 댓글 반응 요약 | 더보기 |
| `PARTIAL` | 일부 댓글만 분석에 포함됐습니다 | 반영된 범위와 제외/갱신 시각 |
| `STALE` | 최근 분석 이후 변경됐을 수 있습니다 | 과거 분석 시각 표시 |
| `NO_DATA` | 현재 분석 가능한 댓글이 없습니다 | 무리한 0% 차트 금지 |
| `COMMENTS_DISABLED` | 댓글을 확인할 수 없는 영상입니다 | 분석 불가 설명 |
| `TARGET_UNKNOWN` | 영상 또는 채널 정보를 확인할 수 없습니다 | 다른 확실한 대상 이용 |
| `ACCESS_DENIED` | 지금 이 자료를 사용할 수 없습니다 | 사용자 권한/소스 범위 설명 |
| `ENTITLEMENT_LIMITED` | 더 넓은 범위는 구독 기능입니다 | 무료 기본 범위 우선 보존 |
| `POLICY_BLOCKED` | 데이터 제공 조건을 확인하는 중입니다 | 결제/재시도로 정책 우회 금지 |
| `ERROR` | 잠시 정보를 불러오지 못했습니다 | 안전한 재시도 |

## 2. 상태 우선순위 (검토 후보)

- **소스/정책 차단**은 구독 여부와 무관하게 우선.
- **식별 대상이 불확실**하면 지난 카드의 데이터를 표시하지 않고 ID 확인 중단.
- **접근 거부/자료 삭제**는 과거 수집 결과를 사용자에게 무조건 재제공하지 않음.
- **실제 0건**과 수집 불가·댓글 비활성·API 오류는 서로 다른 사용자 안내.
- 재시도/정책/구독 처리 버튼은 실제 동작이 없는데 표시하지 않음.

## 3. UI 표시는 고객 중심

- 오류 발생 시 `HTTP 503`, `POLICY_BLOCKED` 등 내부 코드만 크게 띄우지 않음.
- 필요하다면 **자세한 이유**를 Side Panel의 자료 상태 섹션에서 확인 가능.
- 인증/구독과 자료 접근 권한은 별도 확인. 결제했다고 삭제/차단 자료를 다시 제공하지 않음.
- 화면이 바뀌거나 사용자가 다른 대상에 Hover하면 이전 오류·차트는 정리.

## 4. QA 부정 테스트

- [ ] 데이터를 가져오지 못하면 과거 대상 분석을 재사용하지 않는다.
- [ ] `null`을 확인된 `0`으로 보여주지 않는다.
- [ ] 댓글 비활성 영상에 감성 비율을 표시하지 않는다.
- [ ] 정책 차단이 유료 구매 링크로 우회되지 않는다.
- [ ] 네트워크 오류에서 민감한 API 키/원문/내부 로그가 노출되지 않는다.
- [ ] 늦은 응답/중복 요청이 잘못된 카드의 성공 상태로 표시되지 않는다.
