## 1. 분석 상품은 ‘범위’를 확장한다

**기본 이용의 목적:** 특정 영상 또는 채널이 어떤 반응을 얻고 있는지 **짧게 알아보는 것**.

**구독 이용의 목적:** 더 많은 영상과 채널, 더 긴 기간, 더 넓은 비교 집합을 바탕으로 **추세를 조사·저장·추적하는 것**.

| 사용자에게 보이는 기능 | 기본 이용 — 제안 | 구독 이용 — 제안 |
|---|---|---|
| 개별 영상 Hover | 짧은 감성 요약·쟁점·표본 고지 | 자세한 분석 카드/확장 지표 선택 |
| 채널 Hover | 분석 가능한 일부 선정 영상의 요약 | 범위가 넓은 영상군/기간 요약 |
| Side Panel | 영상/채널 단건의 기본 분포·설명 | 상세 이슈·세부 필터·근거 범위 |
| 기간 | 제한된 관측 기간 | 더 긴 기간, 전후 비교와 변화 추이 |
| 범위 | 한 영상/제한된 채널 범위 | 복수 영상·채널 비교 |
| 기록 | 일시적 조회 중심 | 저장·즐겨찾기·모니터링·알림 후보 |
| 산출물 | 짧은 브리핑 | 상세 보고서 초안·검토 도구 후보 |
| 협업 | 개인 탐색 | 향후 고객 조직 내 공유·담당자·승인 기능 후보 |

- **“범위”의 의미:** 허용된 데이터의 분석 **대상 영상 수·채널 수·기간·기능/조회량·동시 작업량**을 조정하는 정책이다.
- **무조건적 정확도 보장 아님:** 돈을 낸다고 결측 댓글, 삭제 원문, 영상 코호트 편향이 사라지지 않는다.
- **플랫폼 권리 우선:** 요금제를 샀어도 API 권한·할당량·데이터 보존/파생·개인정보 정책 Gate를 우회할 수 없다.
- **유료 기능의 실제 가치:** 더 넓은 표본·비교·근거·시계열 도구를 제공하되 출처/한계 고지를 동일하게 유지.
- **미확정:** 표의 구체적 유료 기능은 **제안**이며 요금제에 관한 최종 가격·권한 계약이 아니다.

## 2. 역할(Role)과 구독(Entitlement)을 분리

### 고객 영역

- **개인 고객(Customer Viewer)**
  - 허용된 분석 조회, 본인이 사용할 수 있는 구독 기능만.
- **고객 팀 구성원(Customer Team Member)**
  - 조직에서 부여한 작업·보고서 조회/편집. 유료 조직 가입과 편집권한은 별개.
- **고객 팀 관리자(Customer Team Admin)**
  - 자기 조직의 구성원·프로젝트 접근·팀 보고서 관리. **YUTOPIA 전체 계정/시스템은 관리할 수 없음**.

### 플랫폼 운영/개발 영역

- **YUTOPIA 플랫폼 관리자(Platform Admin)**
  - 구독/청구 상태, 데이터 소스 정책, 수집 Worker, 시스템 장애, 운영 감사 등 **플랫폼 전체**의 별도 관리자 UI.
- **개발자·QA(Developer/QA)**
  - 강제 실패, 권한 거부, 가짜 수치, 가용성 전환, 데모 리뷰 같은 시뮬레이터. 개발/테스트 환경 또는 명시적 내부 도구에만 존재해야 함.

**역할 인가는 서버에서 결정합니다.** 브라우저에서 `role='ADMIN'`, `isPro=true`를 바꾸는 것만으로 접근을 허용하면 안 됩니다.

## 3. 사용자 표면 × 권한 매트릭스 (제안)

| 표면 | 고객 개인 | 고객 팀 관리자 | 플랫폼 관리자 | 개발/QA |
|---|---|---|---|---|
| YouTube Hover 카드 | 허용한 요약 | 허용한 요약 | 고객으로 접근한 경우만 | 테스트 fixture |
| Chrome Side Panel | 구독별 분석 범위 | 조직 권한·구독 범위 | 일상 운영 기능 대신 고객 뷰에서 확인 | 별도 디버그 뷰 |
| 고객 워크스페이스 | 본인 저장/비교 | 자기 조직 협업/승인(정책별) | 지원 목적 최소·감사 있는 접근 | 테스트 환경 |
| 플랫폼 Admin Console | 접근 불가 | 접근 불가 | 승인된 운영 역할만 | 개발 환경 한정 |
| QA 시뮬레이터 | 접근 불가 | 접근 불가 | 필요한 내부 권한 한정 | 허용된 테스트 환경 |

**구독 구매는 플랫폼 관리자 권한, 데이터 이용권, YouTube 채널 소유권을 부여하지 않습니다.**

## 4. 분석 권한 결정 흐름

```text
사용자가 썸네일에 hover
  ↓
대상 videoId 또는 channelId 확인
  ↓
서버 또는 로컬 데모에서 현재 권한 평가
  ├─ 기본 분석 범위 내 → Hover 요약 표시
  ├─ 구독 범위 내 → 심층 내용 허용(더보기로 진입)
  ├─ 이용권 한도 초과 → 필요한 범위와 구독 안내, 임의 결제 실행 없음
  ├─ 소스 데이터 없음 → 데이터 없음 안내
  └─ 플랫폼 정책 차단 → 구독자라도 차단
```

**API 계약 제안**(백엔드에 아직 없음):

- `AnalysisTarget`: `type = VIDEO | CHANNEL`, 안정된 ID, 원천, 조회 맥락.
- `AnalysisSummary`: 대상, 요약, 표본 수/분모, 출처/시각, 상태, 불확실성.
- `AnalysisScope`: 허용 영상·채널 집합, 기간, 표본 선정 방법, 계산 버전.
- `CustomerEntitlement`: 계정·조직·플랜, 접근 가능한 기능/허용량, 상태·만료 시각.
- `QuotaUsage`: 지표별 사용량/갱신 주기/남은 양 — 사업 정책 확정 전 상세 필드 미승인.
- `AnalysisRequest`: 대상/기간/선정 조건/권한, 진행 Job 및 캐시 참조.

이 필드들은 **도메인 모델 후보**이며 기존 `docs/backend-handoff/02_API_CONTRACT.yaml`에 구현된 엔드포인트로 존재하지 않습니다.

## 5. 구독 업셀은 사용자의 흐름을 가리지 않는다

- **기본 Hover·Side Panel Guest-first 방향 승인:** 로그인 전이라도 공개·재사용 가능한 허용 범위 안에서 기본 분석을 먼저 제공. 허용 범위가 없으면 가짜 수치를 만들지 않는다.
- **로그인은 계정이 필요한 행동에서만:** 저장·비교·추적·협업 등 명시적 요청 때 로그인, 성공 후 기존 영상·채널/선택한 작업으로 안전하게 복귀. 인증 기술/세션은 M6 별도 결정.
- **운영 관리자/DEV·QA 별도 경계:** 고객 공통 로그인과 운영 관리자 인증을 격리하고 개발용 합성 데이터를 고객에게 노출하지 않는다.
- **유료 범위 요청 때만 안내:** “최근 더 긴 기간 비교”, “여러 채널 비교” 등 실제 막힌 기능과 필요한 권한을 구체적으로 설명.
- **동작 원칙:** 사용자가 결제를 요청하지 않은 상태에서 자동으로 결제·구독 전환 금지.
- **정상적인 실패:** 구독 만료/결제 실패/이용량 제한 시 기존 기본 요약은 허용 범위 내 유지(제안). 불명확한 권한은 차단, 가짜 성공 표시 금지.
- **예외:** 댓글 없음, 정책 차단, 접근 거부는 유료 구독으로 해결된다고 오해시키지 않음.
- **변경 고지:** 구독 기능·표시 조건을 바꾸면 고객에게 범위·기간·소스 기준 변경을 명확히 알림.
