## 1. 한 문장 제품 정의

**YUTOPIA는 Chrome에서 YouTube 영상을 탐색할 때, 영상 썸네일 또는 채널 항목 위에 마우스를 올리면 해당 대상의 관측 가능한 댓글·반응을 요약해 보여주고, ‘더보기’를 누르면 Chrome Side Panel에서 근거와 추세를 자세히 살펴볼 수 있는 서비스입니다. 구독 고객에게는 분석 대상·기간·비교·추적 범위가 더 넓어집니다.**

- **서비스 사용 위치:** 사용자가 방문한 `youtube.com` 화면.
- **핵심 표면 1:** 썸네일/채널 Hover 미리보기 카드 — 빠른 정보 확인.
- **핵심 표면 2:** Chrome 확장 프로그램 Side Panel — 상세 분석.
- **선택 표면:** YUTOPIA 고객 웹 워크스페이스 — 저장·비교·모니터링·보고.
- **운영 표면:** 플랫폼 관리자 콘솔 — 데이터 수집·정책·서비스 품질·구독 운영.
- **격리된 표면:** 개발/QA 전용 시뮬레이터 — 임의 실패, 강제 권한 변경, 합성 분석.

## 2. 왜 기존 구조를 바꾸나요?

기존 `YU-01~YU-12`는 로그인→채널 연결→프로젝트 생성→수집→분석→검토→보고로 이어지는 **관리·검증 중심 데모**입니다.

그러나 실제 목표 고객의 첫 행동은 프로젝트 생성이 아니라, **YouTube에서 썸네일 위에 마우스를 올리는 것**입니다.

- **기존 문제**
  - 고객에게 수집 실패 시뮬레이션, 근거 정책 상태 강제 변경, 감사 actor 같은 개발/관리 메뉴가 보임.
  - 게임·패치라는 도메인이 일반 영상/채널 분석과 혼재.
  - 구독의 핵심 가치(분석 범위 확장)가 시작 경험에 드러나지 않음.
- **새로운 원칙**
  - 고객은 자연스러운 YouTube 탐색을 계속함.
  - 고객에게는 **결론의 범위·표본·불확실성**을 보여주되 내부 제어 코드를 노출하지 않음.
  - 관리자에게는 실제 운영·감사·예외·사용권 상태 제어만 제공.
  - QA용 강제 상태 변경은 프로덕션 빌드에서 노출하지 않음.

## 3. 사용자 유형 (제품 고객 vs 운영자)

### 고객군

- **일반 시청자**
  - 어떤 내용에 찬반·불만·관심이 모이는지 빠르게 알고 싶음.
  - 로그인 없이 제공할 정보 범위는 후속 정책·요금제 결정 필요.
- **크리에이터 / 채널 운영자**
  - 자기 채널의 반복 피드백과 영상별 추세를 알고 싶음.
  - 채널 소유자 데이터가 필요한 기능에만 별도 동의/권한 검증.
- **기업·브랜드·마케팅 담당자**
  - 캠페인·제품·경쟁 채널의 반응을 비교하고 이슈를 추적.
- **연구자·분석가**
  - 여러 영상/채널의 변화를 기간별로 관측하고 출처·표본·근거를 확인.
- **게임 개발사·퍼블리셔**
  - 위 고객군의 **게임 분야 특화 사례**로 유지. 전체 제품 범위의 한계가 아님.

### 역할 구분

- **Individual / Customer Viewer:** 자신의 허용된 분석 조회.
- **Customer Team Member / Customer Team Admin:** 유료 고객 조직 내부 프로젝트·팀원·보고서 권한. **플랫폼 관리자 아님**.
- **YUTOPIA Platform Admin:** 서비스 전체 계정/수집/정책/장애/감사에 접근하는 별도 운영자.
- **Developer / QA:** 시뮬레이션·진단 기능을 **별도 개발 환경**에서만 사용.

**구독(요금제)과 역할(인가)은 다른 축**입니다. 유료 구독자가 플랫폼 관리자 권한을 얻는 것은 아닙니다.

## 4. 최우선 사용자 경험 (승인 방향)

```text
youtube.com에서 검색·추천 영상 또는 채널을 발견
  → 썸네일/채널에 포인터 올림
  → YUTOPIA Hover Preview 등장(간단한 반응 차트 + 핵심 브리핑)
  → [더보기] 클릭
  → Chrome Side Panel에서 대상에 고정된 상세 분석 표시
  → 더 넓은 영상·채널·기간·비교/추적 기능은 구독 권한 확인
  → 필요할 경우 별도 고객 워크스페이스로 이어짐
```

- **Hover 카드:** 반드시 썸네일 옆의 맥락 유지, 핵심 정보만.
- **더보기:** 사용자 **클릭**으로 열린 Side Panel, DevTools(F12) 자체는 아님.
- **일관된 대상:** 더보기로 연 영상/채널이 Side Panel 분석 대상과 동일해야 함.
- **정보의 정직성:** 자료 없음·댓글 비활성·오래됨·구독 제한·정책 차단을 0건이나 성공으로 위장하지 않음.
- **구독:** 단지 UI를 잠그는 것이 아니라 분석 범위·저장·비교·추적 등 실제 추가 가치를 제공.

## 5. “여론”이라는 말의 범위

기본 자료는 **접근과 분석이 허용된 YouTube 댓글·공개 반응**에 한정될 수 있습니다.

- **대표 표본 아님:** 영상 댓글 참여자의 반응은 전체 국민/시청자/구독자 의견을 대표하지 않습니다.
- **정량 표시:** 분석된 댓글 수, 기간, 대상 영상 수, 제외·미분류 비중, 마지막 분석 시각을 제공.
- **정성 표시:** 감성/주제/대표 의견은 출처 범위와 파생 지표임을 밝힘.
- **실증 구분:** “이런 불만 표현이 관측됨”과 “사실 또는 원인이 검증됨”을 구분.
- **채널 분석:** 분석 가능한 **선정 영상 집합**의 관측 결과로 표시하고, 무조건 채널 전체 의견으로 일반화하지 않음.
- **플랫폼 정책:** YouTube API 데이터에서 계산하는 감성·파생 지표는 별도 정책 조건과 허용 범위를 확인해야 한다. 구독이 플랫폼 이용권을 무한정 늘려주지는 않음.

## 6. 도입 범위와 비목표

### 첫 제품 MVP에서 목표로 하는 것 (제안)

1. 데스크톱 Chrome에서 YouTube 영상 썸네일 Hover 감지.
2. 접근 가능한 고정/캐시 데모 데이터로 짧은 카드 표시.
3. **더보기 클릭** 시 Chrome Side Panel 열고 같은 대상 유지.
4. Side Panel에서 차트·표본 범위·핵심 쟁점·근거/불확실성 표시.
5. 무료(기본) 및 구독(확장) **권한 상태 시뮬레이션**으로 UX 검증.
6. 관리자/QA 정보의 고객 UI 노출 방지, 키보드 접근성과 성능 검증.

### MVP에서 바로 약속하지 않을 것

- YouTube API 실수집·소유자 OAuth·실제 AI 추론(각각 정책/계약 승인 뒤).
- 모든 영상·채널의 댓글을 무제한 분석·실시간 갱신.
- 정확한 유료 가격·요청량·월간 기간·요금제 이름.
- 모바일 Chrome의 동일 Side Panel 동작 또는 모든 브라우저 동시 지원.
- YouTube 플레이어, 광고, 크리에이터 표기를 덮거나 방해하는 행위.
- 기존 `YU-01~12` 전체 관리자 화면을 고객이 그대로 보게 하는 일.
