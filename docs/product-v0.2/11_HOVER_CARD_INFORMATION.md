# 11 — 영상 Hover 카드의 실제 표시 항목·정보 우선순위

> **UX_COMPONENT_SPEC_DRAFT / YU26_MOCK_CARD_CODE_READY / 실제 Chrome 시각 검증 전 / 데이터 MOCK**
>
> 고객은 YouTube 홈의 여러 썸네일 중 하나를 Hover합니다. 카드의 역할은 **3초 안에 이 영상의 댓글 반응이 어떤지 감을 잡고, 더 자세히 볼지 결정하도록 돕는 것**입니다. 관리자 메뉴나 개발 상태 코드는 노출하지 않습니다.

[10 YouTube 홈 기준 화면](./10_YOUTUBE_HOME_HOVER_LAYOUT.md) · [분모·관측 한계](./05_DATA_MEANING_AND_LIMITS.md)

## 1. 카드 위에서 아래로 읽는 순서

1. **브랜드/대상**
   - YUTOPIA 로고·텍스트, “영상 반응” 구분.
   - 대상 영상 제목 최대 2줄, 넘치면 말줄임 및 전체 제목 접근성 제공.
2. **감성 요약**
   - 긍정·중립·부정 비중을 **작은 가로 누적 막대**로 표시.
   - 숫자 옆에 “댓글 기반 YUTOPIA 추정” 안내. 댓글 전체를 대표한다고 주장하지 않음.
   - 미분류/제외·분모가 있으면 한 줄로 범위 고지.
3. **핵심 논점**
   - 최대 2~3개 짧은 제목. 예: “가격 관련 질문”, “설명 이해도”, “배송 문의”.
   - 해당 쟁점이 실제로 검증된 결함·사실인 것처럼 표현하지 않음.
4. **짧은 브리핑**
   - 1~2문장. “분석된 댓글에는 A에 관한 의견이 반복적으로 나타납니다” 형식.
   - 인과·정치/건강 등 민감 속성 추정은 피함.
5. **분석 기준**
   - 분석 표본 N건, 관측 기간, 업데이트 시각.
   - 데이터 일부만 있는 경우 “일부 댓글만 반영”을 함께 표시.
6. **행동**
   - **더보기 →** 단일 주요 CTA: 클릭한 영상 고정 + Chrome Side Panel 열기.
   - 구독 기능이 필요하면 기본 요약을 가리지 않고 상세 패널에서 설명.

## 2. 카드 구조 — 텍스트 와이어프레임

```text
┌─────────────────────────────────────┐
│ YUTOPIA            영상 반응 요약    │
│ 이 영상의 제목 (두 줄 이하)          │
│                                     │
│ 반응 분포  ·  분석 댓글 표본 기준    │
│ 긍정 █████████  중립 ████  부정 ██ │
│                                     │
│ 주로 언급된 내용                     │
│ · 논점 1 (관측 후보)                  │
│ · 논점 2 (관측 후보)                  │
│                                     │
│ “댓글에서는 …라는 반응이 관측됐으나 │
│  전체 시청자의 의견을 대표하지 않음” │
│                                     │
│ 표본 N · 기간 · 마지막 분석시각      │
│                           더보기 →  │
└─────────────────────────────────────┘
```

숫자·문구는 **실제 YouTube 데이터가 없어도 화면 구조를 검증하기 위한 mock**으로만 사용. 실데이터 연동 전 유료/무료를 실제 판매 가능 상태로 표시하지 않음.

## 2.1 26번 Mock Hover 카드 구현 상세

- Shadow DOM 실제 UI 코드는 25번 READY/UNRESOLVED를 구독하고, 한 번에 하나의 카드만 표시한다. 400ms 초기 지연/200ms 이탈 유예는 25번 Controller 계약에 따른다.
- 데모는 **정규 ID만 표시**한다. 영상 제목·실제 채널 이름은 아직 읽지 않으므로, 앞의 1번 UX 원칙인 실제 제목 2줄 표시와 픽셀 정합성은 향후 실제 데이터/UX 검토를 거쳐야 한다.
- 차트 퍼센트·표본 N·주제 2개·브리핑은 고정 합성 예시이며, 실제 YouTube 댓글에 대한 분모·기간/모델 버전·마지막 분석 시각이 존재하지 않는다고 명시한다.
- @handle만 있을 때는 CHANNEL ID 미확정 상태를 보여주고 퍼센트 차트·더보기는 제공하지 않는다.
- 더보기 버튼을 클릭하면 '27~28번 연결 예정' 안내만 나타난다. 26번 단독으로 Chrome Side Panel의 선택 대상을 지정하거나 변경하지 않는다.
- 구현 증거는 [26번 QA](../../extension/tests/QA_26_EVIDENCE.md)에서 확인한다. 모의 테스트 159/159와 실제 Windows Chrome 시각 승인/접근성 승인은 별개다.

## 3. 표시 우선순위와 줄바꿈

- **카드 너비:** 초기 시안 약 320~360px(구현/검증 전 확정값 아님).
- **긴 제목:** 최대 2줄; 채널명·영상 ID/출처는 상세 패널에서 확인 가능.
- **차트:** 여러 주제/감성이 없는 경우 숨기고 “분석 정보 없음” 안내를 차트 대신 제공.
- **브리핑:** 가능한 2문장까지, 텍스트가 길면 축약하되 핵심 단서와 불확실성을 삭제하지 않음.
- **최하단:** 표본·시각·더보기는 카드가 어느 방향으로 배치돼도 가리지 않음.
- **긴 화면:** 본문 스크롤·다른 썸네일 영역을 과도하게 막지 않도록 크기 제한.

## 4. 실제 데이터 부재 시 바뀌는 카드

- **LOADING:** 항목 자리만 보이고 “분석 정보를 확인하는 중” 설명, 이전 영상 수치를 유지하지 않음.
- **READY:** 실제 허용된 요약에 기반한 차트·브리핑·분모 표시.
- **PARTIAL:** 일부 반영되었다는 표시와 선정 범위 고지.
- **STALE:** 마지막 분석 시각을 명시하고 최신이라고 주장하지 않음.
- **NO_DATA/COMMENTS_DISABLED:** 차트 대신 상태·이유, 실행 가능한 다음 행동.
- **POLICY_BLOCKED:** 데이터 정책 미승인이면 감성 추정이나 구독 업셀로 우회하지 않음.

## 5. 고객이 보는 문구와 내부 용어 구분

| 내부 값 | 고객에게 우선 보여줄 말 |
|---|---|
| `READY` | 분석된 댓글 반응 요약 |
| `PARTIAL` | 일부 댓글만 반영 |
| `STALE` | 마지막 분석: … |
| `NO_DATA` | 현재 분석 가능한 댓글이 없습니다 |
| `COMMENTS_DISABLED` | 댓글을 확인할 수 없는 영상입니다 |
| `POLICY_BLOCKED` | 데이터 제공 조건을 확인하는 중입니다 |
| `ENTITLEMENT_LIMITED` | 더 넓은 기간·비교는 구독 기능입니다 |

정식 법적 고지·권리 설명은 **Side Panel의 신뢰/출처 섹션**에 추가하되, 중요한 표본·파생 지표 고지는 Hover에도 유지한다.

## 6. 수용 체크

- [ ] Hover 카드가 **특정 영상**을 보여주며 다른 영상의 수치를 섞지 않음.
- [ ] 차트의 분모와 분석 범위/갱신시각 확인 가능.
- [ ] 브리핑 2문장 이내로 요지를 전달.
- [ ] 내·외부 도구 및 관리/QA 기능 노출 없음.
- [ ] 카드 안으로 마우스를 이동하여 더보기 클릭 가능.
- [ ] 데이터 없는 경우 차트/거짓 분포를 만들어내지 않음.
