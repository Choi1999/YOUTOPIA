## 2. 기술·브라우저 결정

- **T-01 Chrome Manifest V3 및 Side Panel**
  - **확인:** 사용자 제스처(예: Content Script의 더보기 클릭)에서 `chrome.sidePanel.open()` 사용 가능.
  - **결정:** 탭별 컨텍스트/기본 side panel, 메시지 전달 방식을 구현 테스트로 선택.
  - **근거:** [Chrome Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel).
- **T-02 YouTube DOM 변경**
  - **위험:** 홈 추천 카드/Shorts/검색의 DOM이 동적으로 바뀌고 무한 스크롤로 요소가 추가/삭제됨.
  - **대응:** 요소 식별을 안정적으로 설계, 중복 listener/메모리 누수/오탐 방지 회귀.
- **T-03 실제 API·캐시 응답 시간**
  - **위험:** Hover마다 원시 댓글 수집/AI 분류 실행하면 지연·비용·쿼터 초과.
  - **대응:** 캐시된 허용 요약 우선, 로딩/미확보 별도 표시, 수집 Job는 비동기.
- **T-04 브라우저 사이드 패널 위치**
  - **주의:** Chrome Side Panel은 브라우저 관리 UI. YouTube 페이지 요소처럼 픽셀 단위 오른쪽 고정 폭·포지션을 보장하지 않음.
  - **대응:** 패널 안 반응형 UI, 사용자 설정·좌/우 배치 테스트.
- **T-05 Chrome 확장 권한**
  - **위험:** 과도한 host permission·광범위 권한으로 보안/스토어 심사 문제.
  - **대응:** 최소 필요 권한과 `youtube.com` 대상만 먼저 검증, 고객 브라우징 이력 수집 금지.

## 3. 외부 정책·보안 게이트

- **Y-01 YouTube API 데이터 접근**
  - **현재:** 실제 서비스 API 사용 권한/할당량 승인 사실을 확인하지 못함.
  - **대응:** 공개/채널 소유자 데이터를 분리하고 동의가 불필요한 경우 OAuth 강제 금지.
- **Y-02 YouTube 파생 감성 분석**
  - **현재:** 파생 지표 추가 정책은 별도의 Analytics/audit 허용이 필요. **실제 승인 증거 없음.**
  - **대응:** 감성/추천/분류 mock은 합성 데이터로만 개발. 운영 데이터 연결 시 승인 기록 확보.
  - **공식 근거:** [Additional Policies for Derived Metrics](https://developers.google.com/youtube/terms/derived-metrics-policy), [Developer Policies Guide](https://developers.google.com/youtube/terms/developer-policies-guide).
- **Y-03 데이터 보존/삭제·원문 인용**
  - **위험:** 삭제·비공개·갱신·보관 주기·브랜딩 위반.
  - **대응:** 소스별 사용권·마스킹·갱신·삭제 요청 정책 승인 후 실제 데이터 처리.
- **S-01 신원/역할·다른 고객 데이터**
  - **위험:** 다른 고객의 프로젝트/구독/보고서 접근(IDOR/BOLA).
  - **대응:** 인증 세션, 서버 소유권·역할/구독 동시 검사, 부정 테스트.
- **S-02 외부 모델/LLM/MCP**
  - **위험:** 원문·민감정보·개인정보의 제3자 전송.
  - **대응:** 실제 데이터·외부 모델은 정책 승인 전 차단, 시뮬레이션과 분리.
- **B-01 실제 결제/구독 출시**
  - **현재:** 가격·결제·환불·세금·정기결제·권한 갱신/해지 미결정.
  - **대응:** 유료 UI 시연은 가능, **실제 결제 활성화/청구 불가**.
- **R-01 Chrome Web Store 공개 배포**
  - **현재:** 개인정보 고지·권한 최소화·스토어 심사·실API 정책 미충족.
  - **대응:** 로컬 개발 모드 검증 후 별도 승인, 공개 제출 보류.

## 4. 의사결정의 최소 영수증 (결정 후 작성)

모든 `UNRESOLVED` 항목은 다음 내용을 남기고 변경합니다.

- **결정 ID:** 예: `P-08` 또는 `Y-02`.
- **선택:** 어떤 옵션을 채택했고 제외했는지.
- **책임자/승인자:** 실제 승인한 사람(임의로 채우지 않음).
- **근거:** GitHub PR, Notion 문서, API 정책 버전, 테스트 결과.
- **적용 범위:** 고객/관리자/QA, 국가, 기간, 요금제, 데이터 유형.
- **검토 시점:** 법령·정책·YouTube DOM 등 변경에 따라 재검토.

## 5. 지금 진행 가능한 일

- **진행 가능:** 문서 정리, YouTube 홈 다중 썸네일 mock 디자인, Chrome 확장 PoC(합성 자료), Hover 접근성/성능·상태 회귀, 고객 관리자 분리.
- **조건부:** 실제 YouTube API 사용·감성 지표, 인증/DB·조직 저장, 외부 LLM/MCP.
- **별도 승인:** 실제 결제, Chrome Web Store 공개, 사용자 데이터 저장/공유.

**원칙:** 승인 대기가 있다는 이유만으로 안전한 디자인·합성 mock·문서 검수를 중단하지 않는다. 하지만 승인하지 않은 외부 데이터 처리나 배포를 “테스트이므로 괜찮다”고 우회하지 않는다.
