## 3. 개발 착수 전에 고정할 공통 가정

- **데스크톱 Chrome 우선.** 지원 최소 버전은 실제 extension manifest/sidePanel PoC 검증 후 확정.
- **YouTube 홈의 여러 썸네일**을 1차 주요 테스트 표면으로 사용. 다른 페이지·Shorts는 별도 범위로 관리.
- **Hover 카드와 Side Panel의 동일 대상:** `AnalysisTarget = VIDEO | CHANNEL`과 정확한 ID 사용.
- **고객 화면:** 내부 수집 Worker/정책/권한 강제 변경/감사 actor가 노출되지 않음.
- **mock 데이터:** 구독 기능을 시각화할 수 있으나 실제 감성·원문·채널 결과라고 주장하지 않음.
- **분석 신뢰:** 출처·표본·관측 기간·갱신 시각·데이터 미확보 상태 고지.
- **실제 YouTube API 분석:** 파생 지표·보존/삭제/허용 권한을 별도 승인받기 전에는 금지.
