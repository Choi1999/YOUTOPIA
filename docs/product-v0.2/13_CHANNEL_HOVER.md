## 1. 영상 카드와 채널 카드의 차이

| 항목 | 영상 Hover | 채널 Hover |
|---|---|---|
| 대상 | 특정 영상 1개(`videoId`) | 채널 1개(`channelId`) |
| 제목 | 영상 제목 | 채널 이름 |
| 분석 범위 | 대상 영상의 분석 가능한 댓글 | **선정된 채널 영상 집합**의 관측 결과 |
| 결과 고지 | 댓글 분석 기간과 수 | 채널에서 선정한 영상 수·기간·총 분석 댓글 |
| 주요 쟁점 | 단일 영상의 반응 | 선정 영상 간 공통/차별적인 반응 |
| 상세 패널 | `VIDEO` 타입 | `CHANNEL` 타입 |

## 2. 홈에서 채널을 어떻게 Hover하나요?

- **우선 감지 요소**
  - 추천 썸네일 아래 표시되는 **채널 이름 링크**.
  - 채널 아바타·채널 카드 등 정확한 채널 링크를 확인할 수 있는 요소.
- **주의**
  - 썸네일 Hover는 항상 **영상 대상**으로 처리.
  - 같은 추천 카드 안의 채널명 Hover는 항상 **채널 대상**으로 처리.
  - 영상·채널 Hover 카드가 동시에 표시되지 않도록 한 번에 활성 카드 1개.
- **불확실한 URL**
  - `/channel/UC...`처럼 식별 가능한 채널 경로는 해당 ID 사용 후보.
  - `/@handle` 또는 별칭 링크는 확인된 매핑이 없다면 임의로 다른 채널 ID를 생성하지 않음.
  - 서버의 채널 식별/API 정책이 정해지기 전에는 합성/확실한 고정 테스트 채널만 시연.

## 3. 채널 카드의 UI 정보 구조

```text
┌──────────────────────────────────────┐
│ YUTOPIA             채널 반응 요약    │
│ 채널 이름                             │
│ 선정 영상 8개 · 관측 기간 표시 (예시) │
│                                      │
│ 댓글 반응 분포(파생 지표 · 표본 기준)  │
│ 긍정 ━━━━━  중립 ━━━  부정 ━━     │
│                                      │
│ 자주 언급된 주제 ①·②                │
│ 일부 선정 영상에서 ... 관측          │
│                                      │
│ 최근 분석 시각               더보기 →│
```

**8개는 순전히 UI 예시 숫자**이며 실제 채널의 수집량이 아니다. 이미지·차트 사용 시에도 실데이터로 오인되지 않도록 DEMO 배지를 포함.

## 4. 채널 분석에서 특히 막아야 할 과장

- **금지:** “이 채널을 보는 모든 사람의 여론”, “채널 구독자의 85%가 동의”.
- **허용 가능한 표현:** “선정한 영상 8개의 분석 가능한 댓글에서 A 관련 의견이 관측됐습니다.”
- **모집단:** 채널 전체 업로드 영상 수와 **실제 분석 대상으로 선정한 영상 수**를 구분.
- **기간:** 각 영상 게시 시각/관측 범위가 다르다면 기간·코호트 편향을 고지.
- **정책:** 고객이 구독했다고 분석 가능한 원문 범위를 무한 확장할 권리를 얻지 않음.

## 5. 더보기 클릭과 패널 연결

- 채널 카드 **더보기**는 `targetType=CHANNEL`, 확인된 `channelId`를 Chrome Side Panel로 전달.
- 패널 헤더의 대상 종류·이름·선정 영상 수가 Hover 카드와 일치해야 함.
- 영상 Hover의 상세 패널이 열려 있더라도 채널 Hover만으로 패널이 바뀌지 않음. **채널 카드 더보기 클릭 후** 전환.
- 식별 실패·데이터 없음·구독 제한이면 거짓 숫자가 없는 안전한 안내를 표시.

## 6. 수용 체크

- [ ] 영상 썸네일에서 VIDEO, 채널명/아바타에서 CHANNEL로 구분.
- [ ] 영상과 채널 카드의 제목 및 분석 대상 ID가 정확히 일치.
- [ ] `@handle`을 근거 없이 channelId로 간주하지 않음.
- [ ] 채널 카드에 선정 영상 수·관측 기간·분모 표시.
- [ ] 구독 범위 제한/정책 차단 시 다른 채널 데이터로 대체하지 않음.
- [ ] 채널 더보기 클릭 이후 Side Panel이 CHANNEL 대상으로 열린다.
