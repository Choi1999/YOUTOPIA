## 1. 브리핑의 목적

- **결과:** 썸네일에 마우스를 올린 사용자가 **1~2문장으로 영상에 대한 주요 댓글 반응**을 파악한다.
- **길이:** 좁은 카드에서 읽기 쉬운 1~2문장, 최대 2~3개 쟁점.
- **출처:** 분석 가능한 댓글의 관측 결과. 완전성·시각·선정 범위를 함께 표기.
- **한계:** 단순히 댓글에 쓰였다고 실제 결함·허위 사실·인과관계가 입증된 것은 아님.

## 2. 문구 템플릿

| 결과 | 허용할 짧은 예시(합성) |
|---|---|
| 주제 후보 | “분석된 댓글에서 영상의 설명 방식과 가격에 대한 의견이 자주 관측됐습니다.” |
| 의견 충돌 | “이 주제에 대해 긍정과 부정 반응이 함께 관측됐습니다.” |
| 부분 수집 | “현재 접근 가능한 일부 댓글에서 관측된 반응입니다.” |
| 데이터 없음 | “아직 분석할 수 있는 댓글 자료가 없습니다.” |
| 오래됨 | “마지막 분석 이후 변화는 반영되지 않았을 수 있습니다.” |
| 정책 차단 | “현재 조건에서는 해당 분석 결과를 제공할 수 없습니다.” |

## 3. 절대 자동 승격하지 않을 표현

- **대표성 과장:** “모든 시청자”, “유권자 대부분”, “구독자 전체”처럼 댓글 이용자 집합 밖으로 일반화.
- **인과:** “이 영상 때문에 매출이 하락”, “패치 때문에 게임이 고장” 등 검증되지 않은 원인/결과.
- **사실 판정:** 댓글의 불만/논란을 실제 확정된 사실로 선언.
- **민감 속성:** 개인/집단의 정치 성향, 건강, 종교, 인종 등 추론.
- **근거 없는 값:** 댓글이 없는데 구독 전환을 위해 긍정률·추천 점수 생성.

## 4. 로컬 프로토타입 브리핑

- 합성 데이터 `mock-video-A/B/C` 등의 **고정된 테스트 텍스트**로 UI 동작 확인.
- 실제 AI 호출 없이 템플릿/문자열만 사용.
- 고객 UI에는 분석 대상·표본/기간·마지막 분석시각·데모 고지.
- 실제 LLM/댓글 원문을 사용하려면 별도의 데이터 처리/외부 전송 권한 Gate를 통과해야 함.

## 5. 검수

- [ ] 문장 1~2개만으로 주요 댓글 반응이 전달된다.
- [ ] 범위/기간·자료 시각이 구체적으로 표시된다.
- [ ] 모호한 원문에서 실제 진실·원인을 임의 확정하지 않는다.
- [ ] 자료 없음·차단 시 합성 브리핑으로 대체하지 않는다.
- [ ] 다른 영상/채널의 브리핑과 섞이지 않는다.
