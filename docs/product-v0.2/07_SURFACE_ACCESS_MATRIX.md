# 07 — 고객·팀 관리자·플랫폼 운영·QA 접근 권한표

> **ROLE_MATRIX_DRAFT · SERVER_AUTH_NOT_IMPLEMENTED**
>
> **핵심:** 구독 등급은 기능 범위를 정하고, 사용자의 역할은 **어떤 사람/조직의 데이터와 작업에 접근할 수 있는지** 정한다. 둘을 한 개의 `isPremium`이나 `isAdmin` 값으로 합치지 않는다.

[제품 정의](./00_PRODUCT_DIRECTION.md) · [구독 상세](./02_ROLES_AND_SUBSCRIPTION.md) · [기존 화면 재배치](./03_MIGRATION_AND_GATES.md)

## 1. 사용자/역할 정의

- **미로그인 방문자(Guest)**
  - Chrome에 확장 설치 가능 여부, 비로그인 Hover 제공 범위는 아직 미결정.
  - 제3자 개인/조직 데이터 수정은 금지.
- **개인 고객(Customer Viewer)**
  - 허용된 영상/채널 분석 조회. 본인이 저장한 자료 범위만 접근.
  - 구독 여부에 따라 조회 대상/기간/비교·저장 기능 제한.
- **고객 팀 구성원(Customer Team Member)**
  - 속한 조직이 소유한 프로젝트 중 별도 부여된 자원에 접근.
  - 자신이 플랫폼 관리자가 되는 것은 아님.
- **고객 조직 관리자(Customer Team Admin)**
  - 자기 조직의 멤버 초대·권한·보고서 결재(계약 승인 시)를 관리.
  - 다른 고객 조직과 YUTOPIA 플랫폼의 운영 정보에는 접근 불가.
- **YUTOPIA 플랫폼 운영자(Platform Admin)**
  - 허용된 운영 시스템·정책·수집 Job·구독 장애 조사.
  - 고객 개인정보/원문에 무제한 접근하는 계정이라는 의미 아님.
- **개발·QA(Developer / QA)**
  - 시험 환경에서 fixture·실패/정책 상태를 재현.
  - 운영 고객 UI로 시뮬레이터를 배포하지 않음.

## 3. API에서 매번 검증할 것

1. **신원:** 서버가 검증한 사용자/세션으로 행동 주체 식별.
2. **범위:** 사용자가 속한 조직과 대상 영상/채널/프로젝트 권한.
3. **역할:** 자료를 조회/저장/수정/승인할 권한.
4. **구독:** 요청 기능의 분석 기간·영상·채널 수 또는 조회량 제한.
5. **플랫폼 권리:** 실제 YouTube API·데이터/파생 계산/보관 이용 조건.
6. **데이터 가용성:** 원문 삭제, 댓글 비활성, 미수집, 오래됨, 정책 차단.
7. **감사:** 중요한 작업의 인증된 행위자, 상태 변화, 시간과 사유.

**허용 순서:** 위 조건 중 필요한 조건이 하나라도 불확실하면 **데이터를 노출하지 않음**. 클라이언트에서 체크박스나 role 문자열을 바꿔도 서버에서 승인되지 않음.

## 4. 고객 UI에서 보여주지 않을 것

- `DEMO_REVIEWER_UNAUTHENTICATED`, QA 사용자의 `EDITOR/VIEWER/DENIED` 전환 토글.
- `RUNNING/PARTIAL/FAILED`의 가짜 Worker 실행 버튼과 원시 감사 타임라인.
- 내부 정책 버전·서버 Stack Trace·접근 토큰·LLM 모델 호출 비밀.
- 실제로 접근할 수 없는 다른 고객의 프로젝트나 비용·결제 정보.
- 법적/정책 차단은 고객에게 설명하되 내부 관리자 운영 버튼을 같이 노출하지 않음.

## 5. 부정 테스트

- [ ] 조직 A 사용자가 조직 B 보고서 URL의 ID를 바꿔도 접근 불가.
- [ ] 고객 팀 관리자가 플랫폼 Admin Console을 열 수 없음.
- [ ] 구독 구매/유료 플랜 문자열 변경만으로 플랫폼 관리 권한이 생기지 않음.
- [ ] 고객이 강제 실패/가용성/권한 시뮬레이터를 찾거나 호출할 수 없음.
- [ ] 요금제가 허용하더라도 정책 차단된 분석 결과는 볼 수 없음.
- [ ] 권한 없는 사용자가 댓글 원문 또는 보고서를 공유·내보내기 할 수 없음.

**현재 상태:** 역할/서비스 API 미구현, 설계 초안과 부정 테스트 항목만 작성됨.
