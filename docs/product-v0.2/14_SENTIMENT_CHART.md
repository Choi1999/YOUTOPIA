## 1. 기본 차트

- **형태:** 좁은 카드에서도 읽기 쉬운 가로 누적 막대.
- **구성:** 긍정 / 중립 / 부정, 각각 숫자·텍스트 범례.
- **분모:** 감성 분류가 완료된 댓글을 분모로 할지, 전체 분석 대상을 사용할지는 정식 API 계약 때 통일해야 함.
- **미분류:** 해당 범위가 존재하면 표본/하단 고지에 별도 표시.
- **고객 오인 차단:** YouTube 공식 평가나 전체 시청자 만족도처럼 표시하지 않음.
- **접근성:** 막대 색깔만으로 뜻을 전달하지 않고 라벨·수치 및 보조기술 설명 제공.

## 2. 계산과 분모 (데모 정의 예시)

```text
원시 댓글
  ├─ 분석 대상
  │    ├─ 감성 분류 완료 → 긍정/중립/부정
  │    └─ 미분류
  └─ 제외·보류
```

- **실제 0건:** 확인된 분모가 0이면 비율 차트를 만들지 않고 “집계할 표본이 없습니다” 표시.
- **미확정(`null`):** 어떤 비율도 계산하지 않음.
- **부분 수집:** 분포를 표시하더라도 표본이 일부임을 명시.
- **버전:** 분류 모델·기간·소스 코호트가 다르면 이전 차트와 직접 비교 가능한지 판정 필요.
- **예시 mock:** 긍정 45% / 중립 35% / 부정 20%는 레이아웃 검증용 가상 수치이며 서비스 실제 데이터가 아님.

## 3. 카드와 상세의 깊이

| 장소 | 차트 | 추가 정보 |
|---|---|---|
| Hover | 짧은 막대 + 범례 | 분류 완료/미분류/표본·시각 |
| Side Panel | 세부 감성 도표, 기간별 변동 후보 | 원시/제외/분류 버전/데이터 한계 |
| 고객 보고서 | 근거와 비교 적합성 조건 충족 후 | 출처·시간·동일 분모 고지 |

## 4. 실서비스 데이터 승인 게이트

YouTube API 기반 감성 분석 같은 **파생 지표**는 Analytics 사용 사례에 대한 별도 정책 허용·감사 조건을 확인해야 한다. 승인 전에는 목업 차트만 사용하며 실제 API 자료 기반 감성 계산/공개를 진행하지 않는다. [정책](https://developers.google.com/youtube/terms/derived-metrics-policy).

## 5. 점검

- [ ] 제목과 긍정·중립·부정 범례가 읽기 쉽다.
- [ ] 실제 0/미확정/미분류의 의미를 구분한다.
- [ ] 합성 데이터는 MOCK/DEMO임을 확인할 수 있다.
- [ ] 색각 차이가 있어도 텍스트/수치로 이해 가능하다.
- [ ] 파생 감성을 YouTube 공식 지표로 오인시키지 않는다.
