# YUTOPIA Chrome Hover Preview + Side Panel UX 계약 v0.2

> **APPROVED_DIRECTION / INTERACTION_DETAILS_DRAFT / NOT IMPLEMENTED**
>
> 사용자가 승인한 두 가지 형태: **(1) YouTube 영상·채널 Hover 시 간단한 여론 분석 카드, (2) 카드의 ‘더보기’ 클릭 시 Chrome 오른쪽 Side Panel에서 상세 분석.** 아래의 밀리초, 표시 항목 순서, 상태 코드와 메시지 프로토콜은 **검증용 초안**이며 아직 제품 테스트로 확정되지 않았습니다.

## 1. 화면의 구조

```text
+---------------------------------- YouTube 탭 ------------------------------------+
| 사용자는 평소처럼 홈/검색/채널 목록을 탐색                                       |
|                                                                                 |
|    [영상 썸네일]   ← hover → [YUTOPIA 반응 분석 미리보기]                         |
|                         짧은 감성 차트, 상위 2~3 쟁점, 범위/시각, [더보기]        |
|                                                                                 |
|    [채널 항목]    ← hover → [YUTOPIA 채널 반응 미리보기]                         |
|                         선정된 영상 범위/기간 고지, [더보기]                       |
+------------------------------------------------------+--------------------------+
|                   YouTube 원래 콘텐츠                | Chrome Side Panel        |
|                                                      | YUTOPIA 상세 분석        |
|                                                      | 영상/채널 제목+상태       |
|                                                      | 댓글 분포·추세·이슈       |
|                                                      | 근거·표본·구독 기능       |
+------------------------------------------------------+--------------------------+
```

Chrome **Side Panel API**는 브라우저 콘텐츠 옆에 확장 프로그램 화면을 띄우는 정식 기능이다. **F12 개발자 도구를 실제로 열거나 DevTools 내용을 변경하는 것은 아니다.** Side Panel의 크기·도킹 위치는 Chrome 사용자/브라우저가 제어할 수 있어 임의의 고정 폭을 보장하지 않는다.

공식 근거:
- [Chrome Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel) — Chrome MV3, `sidePanel.open()`은 **사용자 동작**에 의해 실행.
- [Chrome Content Scripts](https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts) — 콘텐츠 스크립트는 기본적으로 독립된 환경에서 대상 웹페이지 DOM을 읽고 화면을 추가할 수 있음.
- [YouTube Developer Policies](https://developers.google.com/youtube/terms/developer-policies) — 원천 API 데이터의 권리/출처·보관·표시 준수.
- [YouTube derived metrics policy](https://developers.google.com/youtube/terms/derived-metrics-policy) — Viewer Sentiment Analysis 등의 파생 지표는 정책 개정안 수락 등 **조건을 충족한 경우에 한해** 다룰 수 있으므로 실제 배포 전 별도 승인 필요.

## 2. 영상 썸네일 Hover 카드

### 언제 표시하나요?

- **탐지 대상:** YouTube 홈/검색결과/채널 영상 목록 등에서 사용자 포인터가 올라간 영상 썸네일. Shorts 등 특수 배치/도메인은 적합성 검사 후 별도 범위 선정.
- **식별:** 현재 썸네일 링크의 확실한 `videoId`를 얻을 수 있어야 함. 식별 불확실하면 **대상을 추측하지 않고** 미표시/안내.
- **표시 지연:** 오작동과 과도한 API 조회를 막기 위한 짧은 지연(예: 400ms **초안**) 후 등장. 즉시 나타나야 하는지 UX 테스트로 조정.
- **위치:** 썸네일 우측이 우선. 공간 부족 시 좌측/위·아래로 재배치. 창 밖으로 나가거나 YouTube 원래 컨트롤을 가리지 않도록 해야 함.
- **종료:** 썸네일과 카드 모두에서 포인터가 벗어나면 짧은 유예 시간 후 닫음. 썸네일↔카드 사이 이동 때 깜빡임 금지.
- **중복:** 한 탭에서 한 번에 활성 Hover 카드 1개. 빠른 포인터 이동의 늦은 응답이 이전 카드를 덮지 않음.

### 표시할 정보 (기본 구조 제안)

- **제목:** 해당 영상 제목(필요하면 생략), 분석 대상 명확 표시.
- **감성 요약:** 긍정/중립/부정의 **파생** 분포를 작은 가로 막대 또는 미니 차트로.
- **상위 이슈:** 최대 2~3개 주요 반응·쟁점, 짧은 비인과 브리핑.
- **신뢰 범위:** 분석 가능한 댓글 수, 수집 제외·미분류, 집계 대상·기간/최신 시각.
- **상태 라벨:** `분석 결과 있음 / 일부만 있음 / 오래됨 / 데이터 없음 / 정책상 불가`.
- **CTA:** **더보기** (클릭 시 Side Panel).
- **정직성:** 분석 데이터가 없으면 가짜 긍정률이나 근거 없는 추천을 채워 넣지 않음.

### Hover와 접근성

- `focus`/키보드 탐색만으로도 대등한 정보와 **더보기** 버튼에 접근 가능해야 함. Hover-only 사용성에 의존하지 않는다.
- `Escape`로 카드 닫기, Tab 포커스가 카드 내부/YouTube 화면 이동 때 자연스럽게 동작.
- 크기·명도·스크린리더 라벨은 실제 YouTube 다크/라이트 및 페이지 줌에서 확인해야 함.

## 3. 채널 Hover 카드

- **감지 대상:** 채널 이름·아바타·채널 링크 등 **분석 대상이 확인되는 요소**.
- **채널 식별:** `channelId`가 있으면 사용. `@handle`만 있는 경우 서버/API가 확실히 매핑해야 하며 임의로 ID 생성 금지.
- **분석 범위:** 선정 영상 N개, 관측 기간, 댓글 가용성 등을 명시. **채널 전체 여론**으로 일반화하지 않음.
- **요약:** 전체 선정 영상 중에서 관측된 감성/쟁점의 요약. 다중 영상 비교나 기간 확장은 구독 권한에 따름.
- **더보기:** `targetType='CHANNEL'`과 채널 식별자를 Side Panel로 전달.
- **상태:** 영상 미선정, 댓글 제한, 데이터 미확보, 분석 정책 미승인일 때 별도 안내.

## 4. Side Panel — 더보기 클릭

### 열기 계약

1. 사용자가 Hover 카드의 **더보기** 버튼을 실제로 클릭.
2. Content Script는 클릭으로 확정된 분석 대상 `targetType + targetId`를 전달.
3. 확장 Service Worker는 **해당 사용자 제스처의 흐름**에서 `chrome.sidePanel.open()`을 요청. 비동기 조회를 길게 기다려 사용자 제스처를 잃지 않도록 설계.
4. Side Panel이 열리면 **클릭했던 같은 영상/채널을 분석 대상으로 고정**.
5. 사용자에게 탭/대상 이름과 분석 범위·시각 표시.

### 패널 정보 구조

- **헤더:** `영상/채널`, 제목/ID, 선택된 대상, 마지막 분석 시각, 데이터 상태, 닫기/대상 전환.
- **요약:** 반응 분포·주요 논점·표본 수·제외/미분류 정보.
- **분석:** 세부 감성, 주요 주제/이슈, 댓글 흐름, 분석 기간.
- **근거:** 원문/출처 ID, 허용된 범위, 가용성 및 불확실성.
- **구독 확장:** 긴 기간, 여러 영상/채널 비교, 저장·추적, 보고 기능(권한 확정 후).
- **필수 안내:** 데이터 출처, 분석 범위, 마지막 업데이트, 파생 지표 고지, 실제 전체 인구 대표성에 대한 제한.

### 패널 고정 규칙

- Hover로 다른 썸네일을 스쳐도 **이미 열린 상세 분석을 자동으로 변경하지 않음**.
- 다른 카드의 **더보기**를 클릭한 경우에만 분석 대상을 변경. 필요시 변경 확인 UX를 검토.
- 탭별 Side Panel과 창 전체 Side Panel 중 **탭별 맥락 우선 제안**. Chrome에서 탭 전환/닫기 동작은 테스트하여 확정.
- 이전 영상의 느린 서버 응답을 새 영상에 표시하지 않도록 `requestId / targetId`를 검증.
- 같은 화면의 권한 변경/구독 만료를 즉시 반영하되 개인 정보와 실제 API 토큰을 DOM/URL에 노출하지 않음.

## 5. 상태와 실패 처리

| 상태(제안) | 사용자에게 보일 문구·조치 |
|---|---|
| `TARGET_UNKNOWN` | 어떤 영상/채널인지 확인할 수 없습니다. 버튼 강제 실행 금지 |
| `LOADING_CACHE` | 분석 정보를 확인하고 있습니다. 기다리거나 취소 가능 |
| `READY` | 허용된 분석 요약, 표본·기간·출처 표시 |
| `PARTIAL` | 일부 댓글만 분석됐습니다. 누락 범위 고지 |
| `STALE` | 마지막 갱신 시각 표시, 최신 분석으로 오인 방지 |
| `NO_DATA` | 분석할 수 있는 댓글 정보가 없습니다. 0% 감성값 제조 금지 |
| `COMMENTS_DISABLED` | 댓글을 확인할 수 없는 영상입니다 |
| `ENTITLEMENT_LIMITED` | 기본 이용 범위를 넘어선 상세 분석은 구독 권한이 필요합니다 |
| `POLICY_BLOCKED` | 데이터 제공 조건을 확인할 수 없어 분석을 표시하지 않습니다 |
| `ERROR` | 오류 발생, 안전한 재시도/피드백 방법 제공 |

**진짜 댓글 수 0**과 `NO_DATA`, `COMMENTS_DISABLED`, `POLICY_BLOCKED`는 서로 다른 상태다.

## 6. 기술적 역할 (코드 생성 전 구조 제안)

```text
Chrome Content Script            Chrome Extension Worker       Chrome Side Panel
(썸네일/채널 hover/DOM)     →      (메시지·대상/캐시 제어)    →    (상세 UI)
          │                                │                           │
          └──── 대상 ID 확인               └─ 서버 허용 데이터 조회     └─ 구독 권한/근거 조회
                                            │
                                  YUTOPIA API (미구현)
                                  요약 캐시, 권한, 분석·출처·정책
```

- Hover마다 실제 댓글 전체를 실시간 수집·추론하지 않음. **캐시된 허용 요약 우선**.
- YouTube의 동적 DOM 변화에도 동작하도록 견고한 대상 탐색/정리/중복 설치 방지 필요.
- YouTube의 원래 썸네일 미리보기·클릭·광고·플레이어 조작을 방해하면 안 됨.
- 최소 사이트 권한으로 접근. 플랫폼 규칙 확인 없이 댓글 DOM 대량 스크레이핑을 기본 구현에 포함하지 않음.
- Chrome MV3 `sidePanel` permission과 열기 동작을 검증하되, 브라우저 관리 영역의 크기를 임의 고정한다고 약속하지 않음.

## 7. 프로토타입 검수 시나리오

- [ ] 썸네일 hover → 잠깐 기다림 → 올바른 영상의 미니 카드 표시.
- [ ] 카드 위에 포인터 이동해도 사라지지 않고 **더보기**를 누를 수 있음.
- [ ] 오른쪽/가장자리 썸네일에서도 가려짐·잘림·무한 깜빡임 없음.
- [ ] 더보기 클릭 → Chrome Side Panel이 열리고 **같은 영상 ID**가 표시됨.
- [ ] 패널 열린 상태에서 다른 썸네일 hover → 패널 대상 유지.
- [ ] 다른 썸네일의 더보기 → 해당 대상으로 전환.
- [ ] 영상/채널 항목을 구분하고 표시된 분석 모집단·시각이 일치.
- [ ] 자료 없음·댓글 제한·오래됨·정책 차단을 허위 0%로 대체하지 않음.
- [ ] 키보드 포커스/Enter/Escape로 대등하게 사용 가능.
- [ ] 기본/구독 권한 상태별로 허용 범위만 표시.
- [ ] YouTube 네이티브 UI·재생/광고/스크롤과 충돌하지 않음.
- [ ] 실제 데이터 정책 승인 전 외부 YouTube API·LLM 호출 없음.

**실행 상태:** 현재 Chrome 확장 프로그램은 아직 구현되지 않았다. 위 항목은 **계획된 수동/E2E 테스트**이며 테스트 통과를 뜻하지 않는다.
