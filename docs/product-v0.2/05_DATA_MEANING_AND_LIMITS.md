# 05 — 고객에게 표시할 분석 데이터와 한계

> **DRAFT / 고객 UI 설계 계약 / 실제 YouTube 데이터 미사용**
>
> 목표는 유튜브 썸네일 Hover만으로 ‘반응을 빠르게 이해하는 것’이다. **분석할 수 없는 자료를 0%나 긍정률로 꾸며서 표시하면 안 된다.** 이 문서는 용어·의미를 설명하는 **설계안**이지 API 구현 완료·YouTube 사용권 승인이 아니다.

## 1. 분석 대상

- **영상(VIDEO)**
  - YouTube가 식별하는 특정 영상 1개.
  - 분석된 댓글/반응의 범위와 기간을 명시.
- **채널(CHANNEL)**
  - YouTube가 식별하는 채널 1개.
  - 채널에 속하는 **분석 대상 영상의 선정 집합**과 기간을 명시.
  - 일부 영상 분석을 ‘채널 전체 모든 시청자의 의견’이라고 쓰지 않음.

**대상 ID:** 가능하면 안정적인 `videoId` 또는 `channelId` 사용. 화면의 `@handle` 등은 서버에서 해석을 확인하기 전 다른 채널로 추정하지 않음.

## 2. 수치의 뜻과 표본

- **원시 댓글(raw):** 허용된 기간/선정 대상에서 수집한 원시 댓글 집합.
- **분석 대상(eligible):** 실제로 분석할 수 있는 범위. 제외/보류 댓글과 구분.
- **분류 완료(classified):** 감성 등 분류 작업을 끝낸 집합. 수집 완료 수와 다를 수 있음.
- **미분류(unclassified eligible):** 분석 대상이지만 아직 감성 분류되지 않은 집합.
- **긍정/중립/부정:** 현재 분석 모델이 분류한 수치. **YouTube의 공식 제공 지표가 아닌 YUTOPIA 파생 결과**로 표시.
- **다중 주제/쟁점:** 댓글 하나가 여러 쟁점에 포함될 수 있음. 쟁점 합계를 고유 댓글 수와 혼동하지 않음.
- **범위 고지:** 영상/채널 이름 + 선정 영상 수 + 기간 + 분석된 댓글 수 + 제외/미분류 + 마지막 수집/분석 시각.

## 3. 결과 상태는 숫자와 분리

| 내부 데이터 상태(제안) | 고객에게 표시할 내용 | 하지 말 것 |
|---|---|---|
| `READY` | “댓글 기반 반응 분석” 및 실제 표본·기간·시각 | 전체 시청자 대표 의견으로 표현 |
| `PARTIAL` | “분석 가능한 댓글 일부만 반영” | 미수집분을 0으로 대체 |
| `LOADING` | “반응 정보를 확인하고 있습니다” | 이전 영상의 차트 표시 |
| `STALE` | “마지막 분석 시각: …” | 최신 여론으로 단정 |
| `NO_DATA` | “현재 분석 가능한 댓글이 없습니다” | 긍정 0%, 부정 0% 등의 합성 분포 |
| `COMMENTS_DISABLED` | “댓글 확인이 제한된 영상입니다” | 관측 0건으로 단순 치환 |
| `ACCESS_DENIED` | “현재 이 자료를 사용할 수 없습니다” | 우회 수집 |
| `POLICY_BLOCKED` | “데이터 제공 조건 확인 전에는 분석할 수 없습니다” | 구독 결제로 정책 우회 |
| `ENTITLEMENT_LIMITED` | “이 상세 기능은 구독 범위에 포함됩니다” | 허용 데이터의 기본 요약까지 임의 차단 |
| `ERROR` | “일시적으로 정보를 확인하지 못했습니다” | 성공처럼 표시 |

`raw = 0`은 확인된 모집단의 실제 0건일 때만 참. `raw = null`은 알 수 없음. 두 값을 동일한 차트로 렌더링하지 않음.

## 4. 미리보기와 상세의 정보 깊이

- **Hover Preview — 빠른 판단**
  - 상태/영상 또는 채널 제목, 작은 감성 차트, 주요 쟁점 2~3개, 짧은 브리핑.
  - 표본·기간·최근 분석시각 한 줄과 더보기.
- **Side Panel — 근거 검토**
  - 표본과 분모, 감성 분포/주제/시간 변화.
  - 대표 의견·출처 링크(소스 정책이 허용할 때만).
  - 분석 한계와 불확실성, 최신성, 채널 분석의 선정 영상군.
- **구독 — 더 넓은 범위**
  - 확장 분석 기간·영상·채널 비교, 기록·모니터링/보고 기능 후보.
  - 해당 데이터가 이용 가능한지와 구독 접근 여부는 **별도로 판단**.

## 5. 브리핑 안전 문구

- **허용 가능한 표현**
  - “분석한 댓글 중 배송 경험에 대한 질문이 반복적으로 관측됐습니다.”
  - “선정 영상 5개에서 품질 관련 의견이 많았습니다. 해당 기간의 댓글 참여자 표본 기준입니다.”
- **금지 또는 추가 근거가 필요한 표현**
  - “시청자의 70%가 이 브랜드를 싫어합니다.” — 댓글 표본을 전체 시청자로 일반화.
  - “영상 공개 때문에 매출이 떨어졌습니다.” — 외부 인과 증거 없음.
  - “댓글의 불만이 사실로 검증됐습니다.” — 주장과 실증 검증 혼동.

시청자 성별/나이/인종/정치성향/건강 등 **민감 속성에 대한 추론·프로파일링을 하지 않는다**.

## 6. 파생 지표의 외부 정책 게이트

- YouTube의 공식 개발자 정책은 API 데이터 기반 **감성 분석 같은 추가 파생 지표를 일반적으로 무제한 허용하지 않는다**.
- 2026년 6월부터 적용되는 추가 정책에서는 **허용된 Analytics 사용 사례 및 감사·권한 승인**이 필요한 것으로 안내한다. 임의로 승인됐다고 기록하지 않음.
- **법적·운영 판단:** 필요한 신청/감사와 실제 허용 범위/데이터 보존 및 표시 규칙을 책임자가 확인하기 전에는 실제 API 데이터 감성 계산·상용 배포를 진행하지 않음.
- **문서 근거:** [추가 파생 지표 정책](https://developers.google.com/youtube/terms/derived-metrics-policy), [YouTube 정책 준수 가이드](https://developers.google.com/youtube/terms/developer-policies-guide) — 실제 출시 전 최신 정책 확인.

## 7. QA 예시 (가짜 자료만 사용)

- [ ] 선택한 영상 A에서 다른 영상 B로 바꾼 뒤 A의 늦은 응답이 B 카드에 나타나지 않음.
- [ ] 분석 대상 댓글이 `null`이면 감성 수치를 보이지 않고 원인 안내.
- [ ] `PARTIAL`이면 실제 반영된 범위만 고지.
- [ ] `COMMENTS_DISABLED`이면 실제 댓글 0건으로 표시하지 않음.
- [ ] 채널은 분석 대상 영상 수·선정 규칙을 고지.
- [ ] 구독이 아니어도 정책·자료 가용성에 따라 기본 요약은 독립 판단.
- [ ] 민감 속성 기반 프로파일링을 하지 않음.
