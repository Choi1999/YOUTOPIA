## 1. 일반 사용자 여정

- [ ] **UX-01** YouTube 홈에 최소 4개의 서로 다른 추천 썸네일이 보인다.
- [ ] **UX-02** 영상 B Hover → B에 대한 고객용 카드가 해당 썸네일 옆에 나타난다.
- [ ] **UX-03** 영상 A/C의 수치·제목·쟁점을 B 카드로 잘못 표시하지 않는다.
- [ ] **UX-04** 카드 위로 마우스를 이동해도 사라지지 않고 더보기를 클릭할 수 있다.
- [ ] **UX-05** 오른쪽 끝 영상에서 카드가 화면 밖으로 잘리지 않는다.
- [ ] **UX-06** YouTube 기본 썸네일 미리보기·동영상 클릭·스크롤을 방해하지 않는다.
- [ ] **UX-07** 더보기 클릭 → Chrome Side Panel, 분석 대상 일치.
- [ ] **UX-08** 패널 B가 열린 동안 C Hover만으로 패널 대상이 바뀌지 않는다.
- [ ] **UX-09** C 더보기를 눌렀을 때만 C의 상세 분석으로 바뀐다.

## 2. 분석 정보와 신뢰

- [ ] **UX-10** 긍정·중립·부정의 라벨·표본·시각·분모가 읽기 쉽다.
- [ ] **UX-11** 브리핑은 간단하고 인과·실제 결함·대표성을 임의 확정하지 않는다.
- [ ] **UX-12** 채널 Hover에서는 채널 분석 범위/선정 영상 집합을 명시한다.
- [ ] **UX-13** 진짜 0과 수집 불가(`null`)/댓글 비활성/정책 차단을 구별한다.
- [ ] **UX-14** 기본/구독 고객의 기능 차이를 설명하되 미정 요금·결제를 실행하지 않는다.
- [ ] **UX-15** 합성 데이터 사용 시 MOCK/DEMO임을 명확히 표시한다.
- [ ] **UX-16** 고객 카드/패널에 관리자·QA 디버깅 버튼·실제 OAuth 토큰이 노출되지 않는다.

## 3. 접근성·기술 제약

- [ ] **UX-17** Tab/Enter/Space/Escape로 카드와 더보기를 사용 가능.
- [ ] **UX-18** Chrome Side Panel이 좌우 어느 위치에 있어도 콘텐츠가 읽기 쉽다.
- [ ] **UX-19** YouTube 다크·라이트/창 크기·브라우저 줌에서 색과 텍스트가 읽기 쉽다.
- [ ] **UX-20** 빠른 Hover/무한 스크롤 뒤에도 카드가 중복되거나 늦은 결과가 섞이지 않는다.
- [ ] **UX-21** Chrome 확장 프로그램의 권한 요청이 최소화돼 있다.
- [ ] **UX-22** 실제 YouTube API·감성 파생 계산·외부 모델 호출은 정책 승인 전 실행되지 않는다.
