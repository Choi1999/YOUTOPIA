# YOUTOPIA — G2-J 로컬 영상 근거 순차 탐색 v0.1

> 범위: G2-I Windows 브라우저 수동 QA 10/10 PASS 이후 추가한 순수 프런트엔드 UX 슬라이스.
> 상태: **IMPLEMENTED_IN_ISOLATED_FEATURE_BRANCH / CI_AND_WINDOWS_QA_PENDING / NO_G3 / NO_MERGE**.

## 1. 목적과 변경

- 영상 선택 시 내부 파일 확장자를 제외한 로컬 영상명을 플레이어 제목으로 표시한다. 제목은 외부 YouTube 메타데이터가 아니라 **사용자가 직접 고른 파일명**에서 유도된다.
- 근거 목록 위에 **이전 근거 / 다음 근거** 순차 이동 버튼을 둔다. 이동 대상은 현재 텍스트 검색·모달리티 필터에서 **실제로 보이는 근거만** 포함한다.
- 근거가 선택되어 있다면 그 근거를 기준으로 이동한다. 필터로 선택 근거가 사라지거나 초기 선택이 없다면, 재생 시각에 맞는 근거부터 탐색한다. 첫/마지막 근거에서는 불가능한 방향 버튼을 비활성화한다.
- 운영자 판정 출처·비블라인드·영상 SHA 미검증 안내는 삭제하지 않고 **접힌 상세 보기**로 제공한다. 일반 사용자의 기본 화면을 간결하게 하되 사실과 한계를 보존한다.

## 2. Windows 후속 QA 범위

1. 기존 G2-I 10개 회귀는 이미 PASS였으므로 **신규 G2-J 요소를 집중 검수**한다.
2. Sintel 또는 Tears of Steel MP4 선택 후 플레이어에 영상 파일명이 확장자 없이 표시되는지 확인한다.
3. G2-G JSON 선택 후 **다음 근거**를 순서대로 눌렀을 때 해당 시점으로 이동하고, 마지막에는 버튼이 비활성화되는지 확인한다.
4. 이전 근거로 돌아가기. `FRAME` 필터를 적용한 뒤, **보이는 FRAME 근거 사이에서만** 이전/다음이 작동하는지 확인한다.
5. 운영자 출처 정보가 기본으로 접혀 있고 열어보면 **비블라인드 판정 / SHA 미대조** 경고가 남아 있는지 확인한다.
6. 영상·SRT·JSON·메모는 기존처럼 브라우저 메모리에서만 사용하며 외부 전송이 없어야 한다.
