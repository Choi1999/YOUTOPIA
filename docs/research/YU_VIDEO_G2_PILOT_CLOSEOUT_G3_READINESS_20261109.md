## 4. G3 조건부 진입 평가 — 지금은 NO_GO

G3에서 실제 유료 모델/API를 호출하려면, G0 원안의 동일한 6편/36문항을 충족하거나 축소 파일럿(예: 2편·채택 10문항)용 **평가계약 개정**을 명시적으로 승인받아야 한다. 축소안은 정식 6편/36문항 성능 비교와 동일하다고 주장하지 않는다.

필수 선행 충족 사항:

1. 영상·자막별 합법 이용 범위: 분석·제3자 모델 송신·복제/보관/삭제·초상/제3자 저작물·YouTube 접근경로.
2. 공식 원본·YouTube 게재판의 편집·시간·오디오·자막 정합성 및 비교군 A/B/C의 동등한 입력.
3. 독립 Gold를 요구한다면 AI 초안을 보지 않은 신규 검수자 라벨링, 답안 격리 및 불일치 조정. 비블라인드 채택값은 내부 파일럿 평가 기준으로만 분리 가능.
4. HOLD 2문항 처리 결정: 부재의 실증을 갖추어 개정하거나, 근거를 제시할 수 없다면 파일럿에서 제외하고 제외 사유를 기록한다.
5. 실제 대상 모델/엔드포인트/계정/쿼터·요금·개인정보·전송/보존 조건의 최신 검증. 호출·비용 상한, 자동 재시도 0, API 키 보호, 실행 중단·삭제 정책 확정.
6. 사용자의 **별도 G3 실행 승인** (정확한 대상 영상·모델·호출 수·최대 금액·책임 실행자·시점). 과거 제안된 총 10달러 이하는 **승인된 예산이 아님**.

현재 externalProviderCalls=0, actualSpendUsd=0, g3Authorized=false로 유지한다. G3 API 호출, 프로덕션 DB/댓글 연동, PR 병합·브랜치 삭제를 자동 수행하지 않는다.
