## 안전성·품질 경계

**모든 값은 합성 fixture이다.** 정답과 오답 모두 사전에 만들어졌으므로 계산된 정확도와 비용 차이는 실제 모델 성능·요금·서비스 경제성을 입증하지 않는다.

실 YouTube 영상·음성·자막·댓글 다운로드/입력 0, YouTube 및 LLM API 호출 0, 실제 과금 0, 운영 데이터베이스 및 키 설정 변경 0. 기존 UI 작업 PR과 운영 수집 POLICY_HOLD는 그대로 보존한다.

검증할 부정 사례: 누락/중복 질문·응답, 타 영상 출처, 거짓 라이선스, 권한 없는 실영상 참조, 잘못된 타임코드, 순서 반전, 근거 누락, 잘못된 시각 근거, 근거 없는 주장, 미확인 가격의 0원 치환, 외부 호출 및 재시도.

## 검증 현황

- 스키마·계산기·시험 코드: 신규 실험 브랜치에서만 구현.
- 원격 GitHub Actions: 워크플로 실행 결과를 별도 확인해야 함.
- 실제 영상 해석 품질: NOT_RUN.
- 실제 제공자 단가와 API 접근·처리 권리: NOT_VERIFIED.
- 사용자 병합 승인: NOT_REQUESTED.

**판정:** `G1_OFFLINE_ONLY / LIVE_MODEL_QUALITY_UNKNOWN / PROVIDER_PRICING_UNKNOWN / NO_MERGE`.

다음 G2에서는 허가된 동일 영상과 독립적인 사람이 검수한 정답·근거를 확정하고 공급자 정책을 확인해야 한다. 최초 유료 API 실행은 정확한 영상/호출 수/상한/폐기 계획에 대해 **새로운 명시 승인**을 받아야 한다.
