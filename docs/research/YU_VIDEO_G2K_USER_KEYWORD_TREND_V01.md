# YOUTOPIA — G2-K 사용자 지정 키워드 트렌드 탐색 v0.1

> 2026-11-09 사용자 지시: **YOUTOPIA가 제공하는 키워드가 아니라 사용자가 궁금한 키워드에 접근**할 수 있어야 한다.
> 상태: **USER_KEYWORD_FIRST_UI / LOCAL_CSV_SAMPLE_ONLY / CI_PENDING / WINDOWS_QA_PENDING / NO_REAL_YOUTUBE_SEARCH / NO_G3 / NO_MERGE**.

## 1. 제품 정체성

사용자 자유 키워드 → 관련 영상/채널/댓글 관측 → 시간별 반응 변화 → 근거 탐색. 서비스가 제시한 상위 트렌드 목록은 필수 관문이 아니며, 자동 연관 키워드 확장은 사용자 입력의 범위를 명시적 동의 없이 변경하지 않는다.

입력값에는 미리 등록된 `topicId`, 채널 ID, 영상 ID가 요구되지 않는다. 대화형 질문, 문구, 인물, 제품 또는 개념 등의 사용자 관심사를 검색 시작점으로 허용한다.

## 2. 첫 기능 슬라이스

- 진입 경로: `/analysis/youtube/trend-keywords` (YU-51). 앱 분석 메뉴에 사용자 자유 키워드 탐색 링크 추가.
- 입력: 한글/영문/기타 Unicode를 포함한 1~100자 키워드나 문구. 입력이 없는 초기 화면은 어떤 트렌드도 만들어 보여주지 않는다.
- 자료: **사용자가 직접 선택한 로컬 CSV**만 분석한다. 서버 저장, YouTube 검색, 실제 댓글 API 호출 및 AI 모델 사용 없음.
- CSV 필수 헤더: `comment_id,video_id,channel_id,published_at,text`; 선택 헤더: `video_title,channel_name`.
- `published_at`: 초 단위 ISO 8601 날짜/시간과 타임존(`Z` 또는 오프셋). 예: `2026-11-01T10:00:00Z`.
- 최대 크기 2MiB, 최대 5000개 관측 레코드. 중복 ID/형식 오류/불량 인용부호는 거부하고 기존 정상 자료를 유지한다.
- 분석 기간: CSV에 들어 있는 가장 최근 댓글의 **UTC 게시 날짜** 기준 7일/30일/90일.
- 표시: 기간 내 표본 댓글 수, 문자열 일치 수, 표본 내 비중, 날짜별 언급 분포, 영상·채널별 언급 수, 최신 20건 댓글 텍스트 근거.
- CSV의 제목과 본문은 사용자 제공 자료이며 실제 YouTube 출처·진위와 자동 대조하지 않는다. HTML로 해석하지 않고 일반 텍스트로 렌더링.
- 키워드와 관측 자료는 브라우저 메모리에서만 처리되고 새로고침하면 초기화된다.

## 3. 트렌드 분석 한계

**이 첫 기능은 진짜 YouTube 인기·급상승 키워드 발견 기능이 아니다.** '표본 안에서 특정 검색어가 며칠 동안 몇 건 관측됐는가'만 계산한다.

CSV가 미수집한 날짜는 실제 언급 0건이 아니며, 자료의 수집 완전성과 표본 대표성도 확인되지 않았다. 따라서 조회수 증가율, 유행의 시작 시각, 채널 간 확산 방향, 인과관계와 전체 YouTube 트렌드를 생성하지 않는다.

## 4. 이후 제품화 순서(별도 설계·승인)

1. 사용자 검색어를 받는 실제 YouTube 영상 후보 검색 계약: 검색 범위/시각/언어/수집 쿼터/이용조건 기록.
2. 검색으로 확보한 관련 영상 및 댓글의 적법한 수집·중복 제거·출처 확인, 반복 관측 스냅샷 저장.
3. 동일 범위 기간별 스냅샷의 언급 비중·반응 변화 계산. 수집 누락·비교 불가능성 명시.
4. 키워드 ↔ 영상/채널 ↔ 댓글 원문 ↔ 선택된 영상 구간 근거 연결, 사용자 확인 없는 검색어 자동 확장 금지.
5. 검색어 저장과 알림은 사용자가 명시적으로 선택한 경우에만 제공.
