## O. 완료 판정

- **실행 범위:** 정상 12화면 연결 + 각 화면의 버튼/필터/오류/권한 테스트 + 공통 테마/크기.
- **PASS:** 사용자가 직접 기대 동작을 확인하고 결함 기록이 없음.
- **FAIL:** 기대와 다른 UI·상태·숫자·차단 규칙이 재현됨.
- **BLOCKED:** 환경/소스/설치/정책 문제로 해당 항목을 검사할 수 없음.
- **NOT TESTED:** 아직 수행하지 않은 상태. **자동화 테스트가 통과했다는 이유로 수동 PASS 처리 금지**.
