# UI-R04-C — 전체 화면 그래프 집중 모드 및 자동 비율 도킹 패널 v0.1

## 설계 목표

PR #67의 URL 기반 2.5D 그래프를 Obsidian 3D Graph의 탐색형 사용 경험에 가깝게 만든다. 기존 분석 워크스페이스와 URL 등록 기능을 보존하면서 사용자가 요청할 때만 브라우저 뷰포트 전체에 집중 UI를 띄운다. 브라우저 주소 표시줄까지 숨기는 Native Fullscreen API는 이번 단계에 포함하지 않는다.

## 구현된 동작

- URL을 1개 이상 등록한 뒤 **전체 화면 집중 모드**로 진입. 메인 사이드바, 대형 브랜드 히어로와 기존 분석 패널은 고정 오버레이 뒤로 가려지고 그래프 공간을 최대화한다.
- 기본 진입 상태에서는 그래프만 보인다. 사용자가 **대상 목록**과 **선택 상세** 토글을 직접 켜면 그 패널이 등장한다.
- 도킹 상태 none/list/detail/both에 따라 CSS Grid가 자동으로 그래프와 패널 비율을 조절한다. 그래프는 항상 minmax(0,1fr)로 남는 영역을 채운다.
- 1100px 이하에서는 목록/상세가 그래프 위에 슬라이드형 패널처럼 덮이며, 720px 이하에서는 하단 시트 레이아웃과 단일 패널 우선 동작을 적용한다.
- 목록 검색, SVG 노드 선택, 선택 상세는 하나의 선택 식별자를 공유한다. 목록에서 25번째 이후의 URL을 선택하면 그래프가 해당 24개 페이지로 자동 이동한다.
- 집중 모드에서도 URL 추가·링크 드롭·단일 대상 제거가 가능하며, URL을 추가하면 즉시 선택해 상세 패널을 연다.
- ESC 종료, 탭 포커스 순환, 최초 종료 버튼 포커스 및 종료 후 호출 버튼 포커스 복원, 화면 스크롤 잠금/해제, reduced-motion 설정을 지원한다.

## 의미/정책 불변식

- 등록 URL은 구문을 검증한 ID·핸들일 뿐 실제 대상 존재나 소속을 증명하지 않는다. 제목·썸네일·댓글·감성 지표·연결선을 임의 생성하지 않는다.
- A/B 합성 데모 비교 튜플, 기존 검증 Repository 및 합성 관계 그래프는 변경하지 않는다.
- 저장 구조는 PR #67의 2시간 sessionStorage URL 등록 목록을 재사용하고, 도킹 상태나 URL 원문·댓글·인증정보를 보관하지 않는다.
- 실제 YouTube API, Cloud, 백엔드, Chrome Manifest, L9 보호 저장소, 정책 하드락은 변경하지 않는다.
- 이번 구현은 CSS/DOM/SVG 기반 2.5D이며 Three.js/WebGL 또는 물리 시뮬레이션 도입이 아니다.

## 필수 QA

1. URL 등록 전에는 집중 모드 진입 버튼이 보이지 않아야 하며, URL 1개 이상 등록한 뒤 진입 가능해야 한다.
2. 집중 모드에서는 Graph만 보이는 상태에서 대상 목록을 열면 그래프 폭이 줄고, 상세도 열면 세 영역이 자동 배분되는지 확인한다.
3. 목록을 닫으면 그래프와 상세의 비율이 다시 배분되고, 두 패널을 모두 닫으면 그래프가 전체 폭을 사용하는지 확인한다.
4. 목록에서 ID를 선택하면 같은 노드가 하이라이트되고, 상세에는 ID·종류·미확인 상태가 나타난다. 분석·소속·메타데이터를 임의 표시하지 않는다.
5. 집중 모드에서 URL 입력과 링크 드롭을 실행하면 기존 목록·그래프에 즉시 반영된다.
6. 여러 URL(예: 27개)을 등록하고 목록에서 오래된 대상을 선택하면 그래프의 관련 페이지가 자동 선택된다.
7. Esc/종료 버튼으로 닫으면 브라우저 스크롤과 포커스가 복원되고 등록한 목록은 유지된다.
8. 마지막 URL을 제거하면 집중 모드가 정상 종료되고 UI가 기존 첫 화면으로 복귀한다.
9. 1440px/900px/390px/320px, 다크·라이트, 모션 감소 설정, 키보드 Tab/Shift+Tab/Enter, 터치와 화면 폭 변경을 실기기에서 확인한다.
10. 기존 등록 URL/합성 A/B 비교/분모/정책 관련 모든 회귀 테스트와 Windows offline CI를 통과한다.
