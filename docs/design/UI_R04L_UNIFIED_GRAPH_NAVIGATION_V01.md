## 소비자 UX 계약

1. **그래프 통합 검색:** 입력 검색은 현재 등록된 영상/채널의 canonical ID,
   canonical URL 및 사용자 지정 그룹 이름/ID의 로컬 문자열 검색만 한다.
   조회하지 않은 영상 제목·실재성·채널 관계를 자동 완성하지 않는다.
   검색 즉시 일치한 노드/그룹을 강조하고 첫 결과가 있는 페이지로 이동한다.
   직접 선택할 수 있는 결과는 8개까지 보여 주고 전체 검색 건수를 표시한다.
   검색이 없는 경우 정상 그래프 배치를 유지한다.
2. **위치 이동 및 중심 정렬:** 검색 결과·일반 노드·미니맵 핀 선택은
   해당 탐색 단위 페이지로 이동하고 2.5D 화면의 중앙에 배치한다.
   그룹에 포함된 멤버는 사용자 의도에 따라 접힌 그룹에서 일시적으로
   펼쳐 표시되며 그룹의 저장된 접기 설정을 임의 변경하지 않는다.
   사용자가 캔버스를 팬/줌한 뒤에도 '선택 중심' 버튼으로 다시 정렬할 수 있다.
3. **탐색 이전/다음:** 방문을 확정한 노드 또는 그룹을 최대 40개까지
   컴포넌트 메모리에 보관한다. '이전 탐색'과 '다음 탐색'으로 이동한다.
   검색 입력 과정의 임시 미리보기는 기록하지 않는다. 뒤로 이동한 뒤 새
   대상을 방문하면 예전 미래 기록은 분기 제거한다. 이미 등록 삭제된 ID는
   복원하지 않고 건너뛴다. URL이나 식별자 외부 전송 없음.
4. **그래프 미니맵:** 현재 24개 탐색 단위의 상대적인 **2.5D 위치 개요**만
   간략히 표시한다. 점을 클릭하면 대상/그룹으로 이동·중심 정렬하며,
   선택과 검색 강조 상태를 반영한다. 펼쳐진 그룹의 멤버들은 허브의
   미니맵 한 점으로 표시한다. 실제 YouTube 관계 지도나 geospatial map 아님.
   미니맵을 사용자 버튼으로 숨길 수 있다.
5. **접근성/반응형:** 이름 붙은 검색 입력·검색 결과/미니맵 영역과
   방문 기록 버튼을 제공한다. 키보드 포커스 및 기존 Esc/Tab 정책을
   유지하고 720px 이하에서는 검색/미니맵 크기를 축소한다.
   reduced-motion을 준수한다.
