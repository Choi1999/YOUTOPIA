# UI-R04-M — 사용자 북마크 및 그래프 탐색 결과 필터 (v0.1)

## 1. 목적 및 부모

- 부모: UI-R04-L, Draft PR #76, 커밋 580ddd9738cc6517d731107b317b6d5483feadc2.
- 목적: 등록된 영상·채널과 사용자가 구성한 그래프 그룹을 북마크하고
  수많은 탐색 단위 중 필요한 것을 유형별로 다시 찾는다.
- 기능 개발 승인만 받았다. 병합/배포/실 YouTube API 호출은 별도 승인 대상이다.

## 2. 소비자 기능 계약

1. 그래프 노드 또는 그룹을 선택하면 '☆ 북마크' 버튼이 활성화된다.
   북마크 추가·해제, 그래프/그룹/미니맵의 저장 표시가 일치해야 한다.
2. '북마크 N개' 메뉴에서 저장된 영상·채널·그룹 목록을 보고,
   항목을 선택해 해당 24개 단위 페이지로 이동하고 중심에 맞출 수 있다.
   개별 북마크 제거는 원본 등록 URL·그룹·기존 분석 데이터를 삭제하지 않는다.
3. 기존 통합 검색 입력에 '탐색 결과 유형' 필터를 추가한다:
   전체 결과, 영상만, 채널만, 그룹만, 북마크만.
   검색어가 비어도 필터를 지정하면 해당 유형의 탐색 항목을 표시한다.
   이 필터는 **검색 결과 목록에만 적용**한다.
   그래프 노드 자체를 숨기거나 등록 순서·관계·그룹 구성·24개 페이지를 변경하지 않는다.
4. 그룹에 속한 영상의 북마크도 유지한다. 북마크에서 해당 영상을 찾으면
   기존 UI-R04-L의 접힌 그룹 일시 펼치기와 중심 정렬을 사용한다.
5. 일반 그래프와 전체 화면 집중 모드는 북마크 상태를 공유한다.
   기존 왼쪽 목록·선택 상세·가변 분할바·검색 결과·전체 미니맵을 보존한다.

## 3. 데이터 및 안전 계약

- 새 모델: workspaceGraphBookmarks.ts (단일 책임, 외부 API 호출 없음).
- 저장 위치: 탭별 sessionStorage 키 youtopia-workspace-graph-bookmarks-v1.
- 저장 필드는 version=1, savedAt, bookmarks 목록의 kind(target/group) 및
  이미 등록된 canonical key뿐이다. 원본 URL, 채널 제목, 댓글, API 키,
  감성 데이터, browsing history를 저장하지 않는다.
- 북마크는 최대 32개, 엄격한 JSON 스키마/크기 8KB, 기존 URL 보관 정책과
  동일한 2시간 TTL을 따른다. 중복, 등록되지 않은 ID, 삭제된 그룹 및
  손상된 데이터는 복원하지 않는다.
- URL이나 그룹 제거 후 참조를 정리하되, 유효한 기존 북마크를 유지한다.
  저장소 접근 오류는 UI를 중단하지 않고 메모리 사용으로 처리한다.
- 유튜브 댓글/메타데이터 조회, 관계 추론, 새 권한/키/외부 요청,
  POLICY_HOLD 및 첫 실호출 하드락 변경을 전혀 포함하지 않는다.
- 사용자에게 운영 Cloud/쿼터/QA 패널을 노출하지 않는다.
