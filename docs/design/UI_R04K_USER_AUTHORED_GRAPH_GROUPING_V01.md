# UI-R04-K — 사용자 지정 그래프 노드 그룹화 v0.1

## 1. 목적과 경계

사용자는 영상·채널 URL을 계속 추가하면서 공간형 그래프를 개인적으로 정리한다.
이 기능의 그룹은 사용자 작성 조직화 단위이며 실제 YouTube 영상·채널 관계,
소유권, 댓글 유사성, 감성/분석 결과, 추천 관계 또는 데이터 수집 승인을
증명하지 않는다.

- 부모: UI-R04-J, Draft PR #74, HEAD 5f8c862d2d6eb79b31cd3ce789c21c8ec77d176b.
- 범위: 그래프에서 복수 노드 선택, 그룹 이름/색상 설정 및 변경, 접기·펼치기,
  그룹 검색/이동, 그룹 해제, URL 삭제 시 참조 정리.
- 비범위: 그래프의 추론 edge, 자동 분류, 영상·채널 메타데이터 조회, 댓글 수집,
  원본 등록 ID 변경, 계정 동기화, 서버 쓰기, 병합, 배포, 실 YouTube API 호출.
- 일반 사용자에게는 그룹 편집 도구만 보이며 내부 Cloud/quota/policy 진단 UI는 제외한다.

## 2. UX 계약

1. 그룹 선택 모드를 켜고 아직 그룹에 속하지 않은 노드를 2~12개 선택한다.
   선택은 페이지를 넘어 유지할 수 있으나 상한을 넘을 수 없다.
2. 그룹 만들기에서 1~40자의 이름과 4가지 고정 색을 선택한다.
   등록되지 않은/중복된 ID, 이미 다른 그룹에 속한 노드는 추가할 수 없다.
3. 그룹 N개로 관리 영역을 펼쳐 이름 변경, 색 변경, 그룹 검색(이름 또는 멤버 ID),
   해당 그룹 페이지로 찾기, 접기·펼치기, 위치 초기화, 그룹 해제를 수행한다.
4. 접기 상태는 여러 노드를 하나의 그룹 허브로 표현한다. 펼치면 해당 그룹에
   소속된 개별 영상·채널 노드가 그래프에 나타난다. 이는 시각적 묶음이며
   확인되지 않은 관계 edge를 생성하지 않는다.
5. 그룹 허브를 포인터로 끌면 구성 노드가 함께 이동한다.
   허브 포커스에서 Alt+방향키는 20px, Alt+Shift+방향키는 40px 이동,
   Alt+Home은 위치 초기화다. 오프셋은 각 축 ±320px 제한이다.
6. 집중 모드의 대상 목록에서 접힌 그룹의 구성원을 선택하면 그 선택 대상은
   현재 보기에서 일시적으로 펼쳐져 표시된다. 페이지는 기존 선택 키로 이동한다.
   그룹 상태 자체를 실데이터 관련 증거로 표시하지 않는다.
7. 기존 24 탐색 단위(단독 대상 또는 그룹) 페이지를 유지한다.
   펼쳐진 그룹의 노드는 허브 주위에 함께 표시되며 전체 대상 등록 한도 128은 불변.
   그룹 생성/해제로 URL 삭제·분석·A/B 데이터는 변하지 않는다.

## 3. 데이터 및 저장 계약

- workspaceNodeGroups.ts는 원본 workspaceUrlTargets.ts와 별도 순수 모델이다.
- 사용자 탭 sessionStorage의 youtopia-workspace-node-groups-v1에
  version=1, savedAt, id/name/color/memberKeys/collapsed/offsetX/offsetY 형태의
  유효 데이터만 저장한다. 등록 ID는 기존 canonical kind:ID 키이며
  원본 URL, 비밀키, 댓글, 외부 API 응답은 저장하지 않는다.
- 최대 32개 그룹, 그룹당 2~12개, 구성원 중복 불가, 크기 상한 24KB,
  등록 URL과 일치하는 구성원만 허용. 2시간 TTL과 손상·만료·무효 레코드 거부.
- 등록 URL이 제거되면 멤버십을 자동 조정하고 2개 미만인 그룹은 해제한다.
  저장소 접근이 거부되면 앱은 메모리 상태로 계속 작동한다.
- URL 등록, 영상 이미지 opt-in, 미확인 대상 표시, focus/dock 레이아웃,
  정책과 첫 실호출 하드락은 변경하지 않는다.
