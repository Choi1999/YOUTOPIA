# YOUTOPIA UI-R01~R04 — 반응형 분석 워크스페이스 디자인 시스템 / PoC v0.1

## 작업 승인 범위

사용자는 Lusion의 고대비 아트 디렉션과 Spline의 절제된 입체 컴포넌트, 데이터 중심 SaaS 레이아웃을 YOUTOPIA 리디자인 방향으로 승인했다. 본 문서는 특정 사이트의 자산·레이아웃을 복제하지 않으며 고유한 YOUTOPIA 시각 체계를 정의한다.

## UI-R01 — 시각 토큰

- 밝기 구조: dark navy #080D19 기반 위 #11192B 표면, 강조 cobalt #7691FF 및 mint #63DECF. 밝은 테마는 #F1F4FB와 #FFFFFF 배경, #4765D1 강조.
- 앱 전체 기존 토큰 대신 .app-shell--immersive-workspace 범위에서만 덮어써 이전 화면 디자인·시각 테스트 영향을 제한한다.
- 타이포: 기존 DM Sans/Noto Sans KR를 유지하고 제목과 본문에서 무게·크기·여백만 조정. 새 글꼴/이미지 다운로드는 추가하지 않는다.
- 표면: 모서리 15–28px, 낮은 명암의 구분 테두리, 제한적 blur, 작은 선택 동작. 색상만으로 상태를 설명하지 않는다.

## UI-R02 — 화면과 반응형 배치

- 1280px+: 224px 세로 탐색 + 넓은 콘텐츠; 메인 분석 영역과 보조 근거 레일을 분리한다.
- 721–1279px: 72px 탐색 레일(기존 아이콘 유지); 본문을 1024px 고정 너비 없이 유동 배치한다.
- 720px 이하: 모바일 상단 탐색 및 명시적 확장 버튼, 본문 한 열; 마우스 hover가 없어도 모든 이동·선택 조작을 허용한다.
- 430px 이하: 장식용 3D 장면을 숨기고 분석 콘텐츠만 렌더링한다. 페이지 최소 너비는 320px이며 가로 스크롤 없이 이용하도록 레이아웃을 구성한다.
- 터치 대상은 가능한 42px 이상, 키보드 탐색과 focus-visible 유지. 모바일 메뉴는 aria-expanded/aria-controls 상태로 접근 가능해야 한다.

## UI-R03 — 워크스페이스 시안

- 히어로: '통합 분석 워크스페이스'라는 기존 기능명을 유지하고 강한 타이포와 가벼운 입체 비주얼로 시각적 도입을 구성한다.
- 메인 열: 대상 선택 → 검증 요약 → 등록 대상 검색 → 기존 분석 화면 링크.
- 근거 레일: 최근 선택 대상 → 검증된 합성 표본·분모 상세. 작은 화면에서는 본문 뒤로 순차 이동.
- 기존 분석 Repository, sessionStorage v1/TTL, 비교 순서, UTM 실패 닫힘, 미등록 ID 차단의 의미를 바꾸지 않는다.

## UI-R04 — 제한적 3D 프로토타입

- CSS perspective/rotateX/rotateY로 구형 코어 및 궤도 구조를 만든다. 장식용 DOM은 aria-hidden으로 처리.
- WebGL·Spline 라이브러리 추가, GPU 독립 루프, 새로운 네트워크 요청은 없다. 현 단계는 실제 3D 데이터 차트가 아닌 CSS 3D 디자인 PoC임을 명시한다.
- prefers-reduced-motion에서는 애니메이션과 전환을 제거하고, 좁은 모바일 화면은 3D 장식을 숨긴다.
