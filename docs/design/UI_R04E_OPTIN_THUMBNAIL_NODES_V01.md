# UI-R04-E — 영상 썸네일·채널 프로필 노드 고도화 v0.1

## 사용자 요청

URL을 붙여넣어 영상/채널 노드가 생성되면 썸네일이나 채널 프로필 이미지가 함께 보이는 Immersive Analytics UI. 표시 범위는 Obsidian-style URL 그래프, 등록 대상 카드, 집중 모드 대상 목록, 선택 상세. 원래 요구는 실제 채널/영상 이미지를 시각적으로 식별하는 것이지만, 이 버전의 원격 이미지 권한과 메타데이터 제약을 구분한다.

## 구현 범위

- 공통 WorkspaceTargetArtwork가 영상 16:9 이미지, 채널 원형 프로필 자리, 모바일·목록·카드·상세형 아트워크를 통일한다.
- URL 등록은 기존대로 즉시 발생하며, 첫 렌더는 공통 플레이스홀더다. 가로세로 비율이 미리 고정되어 이미지 실패나 수신 전에도 노드·패널이 흔들리지 않는다.
- 사용자가 **영상 이미지 미리보기 켜기**를 클릭한 경우에만 URL에서 검증된 11자 VIDEO ID를 사용해 `https://i.ytimg.com/vi/<ID>/hqdefault.jpg` 이미지를 브라우저 `<img>`로 로드한다. `loading=lazy`, `decoding=async`, `referrerPolicy=no-referrer`, `draggable=false`를 적용한다.
- 동의는 현재 페이지의 React 메모리 상태에만 보관한다. sessionStorage, URL, 계정, 쿠키나 외부 API로 동의를 저장하지 않는다. 새로고침하면 미리보기는 다시 꺼진다. 집중 모드와 기본 페이지의 활성 상태는 같은 값으로 동기화한다.
- 이미지가 로드되지 않으면 기존 아이콘과 `미확인` 표기로 안전하게 대체한다. 이미지 로드 성공은 해당 영상 존재나 유효한 댓글 분석 완료를 보증하지 않는다.
- 채널 ID/핸들에서 실제 프로필 이미지 URL을 만들지 않는다. 채널 프로필은 승인된 검증 메타데이터 소스가 없으므로 `프로필 미조회` 또는 `핸들 해석 대기` 표시를 유지한다. 실제 채널 이미지 자동 표시는 **후속 별도 정책 승인/구현 대상**이다.

## 네트워크/보안 경계

- 기본(미리보기 OFF): 새 외부 이미지 요청 없음. 사용자가 명시 클릭한 경우: 공개 영상 이미지 CDN(`i.ytimg.com`)에 대한 브라우저 이미지 요청만 발생할 수 있다. 네트워크를 사용할 경우 사용자의 IP 등 브라우저 연결 정보가 이미지 서버에 전달될 수 있다.
- 영상 CDN과 Google YouTube Data API, 채널 메타데이터 조회, 댓글 API·첫 실제 수집 호출은 명확히 구분한다. 어떤 메타데이터·분석 API 호출도 추가하지 않는다.
- 영상 ID 정규식으로 CDN 경로를 구성하므로 사용자 제공 임의 호스트를 `<img src>`로 사용하거나 임의 외부 이미지를 넣을 수 없다.
- `POLICY_HOLD`, verifiedCount=0, 실댓글 수집 전송 하드락 false, Chrome Manifest 및 Google Cloud/백엔드/운영 배포 불변. 사용자 승인 범위를 보수적으로 영상 공개 이미지 미리보기에 한정한다.
- 실제 데이터 검증 없이 썸네일의 진위성·저작권 적합성·미디어 내용·이미지 캐싱 가능 여부를 단정하지 않는다.

## QA

1. 미리보기 OFF에서 유효한 영상/채널 URL 추가 시 그래프/카드에 이미지 `src`가 없고 기본 아트워크가 보인다.
2. 영상 이미지 미리보기 ON 클릭 시 VIDEO 노드/카드에 i.ytimg.com 이미지 요청이 연결되고 `OFF` 시 모두 해제된다.
3. CHANNEL ID 또는 @handle은 ON 상태라도 실제 이미지 요청을 만들지 않고 채널 프로필 미조회 상태를 표시한다.
4. 이미지 요청 실패는 아이콘 fallback. 노드 선택/대상 삭제/등록 유지가 정상 동작한다.
5. 전체 화면 집중 모드의 영상 노드/목록/선택 상세에 동일 미리보기가 표시된다. 모드 안팎 토글 동기화.
6. 새로고침 후 기존 URL 등록 목록은 복원되지만 이미지 미리보기 ON 상태는 **복원되지 않는다**.
7. 1440/900/390/320px, 다크/라이트, 키보드/터치, `prefers-reduced-motion`, 저속 네트워크 및 썸네일 404를 수동 검수한다.
8. 기존 합성 A/B 비교, 분모/주제 근거, URL 검증·저장, 정책 게이트, 오프라인 통합 CI 회귀를 통과한다.
