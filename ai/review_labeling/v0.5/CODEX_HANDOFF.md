# Codex 적용 지침 — v0.5

먼저 이 저장소의 AGENTS.md와 `ai/review_labeling/CURRENT.json`을 읽는다.
그 다음 GUIDELINES_KO.md, taxonomy.json, pilot70_review.md 순서로 확인한다.

## 현재 전달 상태

이 변경은 분류기준과 70건 파일럿의 재분류다. 실행 서버나 학습 코드가 변경됐다는 뜻은 아니다.
기준 브랜치 dev에는 이 작업 시점 README만 있었다. 백엔드·프런트 코드나 별도 Codex 작업 내용을 자동으로 포함하지 않는다.
작업 중인 다른 브랜치에서 사용한다면 이 디렉터리와 CURRENT.json을 가져오고 기존 AGENTS.md에 이 참조를 병합한다.
새 브랜치에 올렸다는 사실만으로 이미 실행 중인 Codex 작업의 checkout이 자동 갱신되지는 않는다.

## 적용 순서

1. `python3 ai/review_labeling/v0.5/validate.py`를 실행한다. 파일 해시·전체 70건·근거·이관·집계 검증을 통과해야 한다.
2. 기존 코드의 taxonomy loader, 라벨 목록, 정답 변환기, 예측 JSON schema, GPT/Gemini 프롬프트, 지표 코드, DB 저장 계약을 찾는다.
3. 기존 상위 항목만 출력하는 코드에 파일을 단순 덮어쓰지 않는다. **leaf_id**를 독립 출력 단위로 연결하고 실제 대상·감성·근거·조건을 저장한다.
4. `pilot70.json`은 새 v2 스키마다. held_annotations는 정답 변환 금지, excluded_spans는 입력 삭제 금지. 모든 파일럿의 learning_eligible=false를 지킨다.
5. `source_review_acceptance`는 옛 초안의 승인이다. 새 분류의 `classification_review.user_verified=false`를 무시하고 gold로 승격하지 않는다.
6. 실제 훈련 데이터로 leaf별 분포를 확인하고 학습 가능 범위를 정한다. 이번 등록 라벨 수와 모델이 실제 학습한 라벨 수를 분리 보고한다.
7. 체크포인트에 taxonomy_version, taxonomy_sha256, label_to_id 해시, 전처리 버전, 입력 범위를 저장한다. 추론/서비스에서도 같은 값을 검증하고 불일치면 실패시킨다.
8. 이전 12개 부모 라벨의 체크포인트를 71개 leaf 모델처럼 취급하지 않는다. 모델 구조·학습 데이터와 연결해 새 버전으로 학습·평가한다.
9. API 모델과 자체 NLP가 동일 텍스트·문맥·라벨 정의·고정 시험 세트를 쓰게 한다. AI로 만든 정답을 동일 AI 비교의 독립 정답이라고 주장하지 않는다.
10. leaf별 Precision/Recall/F1·support, Macro/Micro F1, 오류 사례, 적절한 혼동표와 학습 곡선을 저장한다. 시험 표본 0인 라벨은 0점 성능으로 꾸미지 말고 N/A 처리 및 평균 정책을 명시한다.
11. 서비스 집계는 고유 리뷰 수를 분모로 하고, leaf별 양극성을 보존한다. 원문 전체/전처리/분석/내용 없음/HOLD/실패 건수와 버전을 함께 보낸다.
12. 실제 구현·테스트·서버 배포 여부를 각각 보고한다. 이 자료 검증을 GPU 학습·서비스 통신 검증으로 보고하지 않는다.

## 꼭 유지할 경계 사례

- 4: 충돌 부정 / 재접속 부정 / 로딩 부정. 원인·운영 대응을 추정하지 않는다.
- 14: 업데이트·모드 때 재접속해서 즐긴다는 긍정. 플레이 때마다 종료된다는 평가로 바꾸지 않는다.
- 31: 내레이터는 HOLD. 번역 비유를 실제 현지화 평가로 분류하지 않는다.
- 35: 오래 질리지 않음은 LONGEVITY. 새 회차를 플레이했다는 주장을 만들지 않는다.
- 44: 충돌과 진행 손실은 동일 사건에 연결된 별개 현상. 두 개의 리뷰로 세지 않는다.
- 53: 음악 긍정 / 일반 사운드 긍정. 후자를 효과음으로 확정하지 않는다.
- 57: 스토리 일반 약한 긍정 / 전개 속도 부정. 스토리 일반을 개연성 호평으로 바꾸지 않는다.
- 58: 친구가 없다는 말만으로 협동 강제 비판을 만들지 않는다.
- 60: 버그 전반과 진행 장애. 반복 로드는 저장 데이터 소실의 증거가 아니다.
- 63/68: 캐릭터 매력·귀여움의 세부 대상 미상. 외모·성격을 추정하지 않는다.
- 67: 번역 표현 부정. 조작·더빙 연기·오역으로 바꾸지 않는다.
- 69: 길찾기 긍정 / 설정 가능 긍정 / 타격감 긍정 / 조작감 부정.
- 70: 더빙 긍정 / 다양성 긍정 / 재플레이 긍정. 별도 전략 플레이 호평은 추가하지 않는다.

원문과 주석은 제삼자의 리뷰를 포함한다. 이 저장소에 별도 데이터 재배포 라이선스를 부여한 것으로 간주하지 않는다.
