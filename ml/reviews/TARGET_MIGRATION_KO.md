같은 leaf의 긍정과 부정을 모두 남기며 혼합은 파생한다. 상위 항목도 leaf·감성 쌍을 유지한다. 대상·조건·근거·강도·제외 문자열·HOLD·source_opinion_id·검수 이력을 보존한다. 이전 리뷰 수락이 새 AI 세분류의 검수 완료를 뜻하지 않는다.

v0.5 사전은 `legacy/taxonomy-v0.5.json`, 지침은 `labeling/GUIDELINES_v1.2.0_KO.md`, 출처는 `labeling/SOURCE_v0.5.json`에 보존한다. 구형 체크포인트는 새 정책으로 거부하고 재학습한다. 사전 ID를 바꿔 기존 가중치를 새 모델로 해석하지 않는다.

## 검증과 실제 실행의 구분

실제 v0.6 파일럿: 100건, 활성 의견164개, HOLD8개, 새 AI 세분류 사용자 검수30건, 이전70건은 기존 검수 상태 유지, 메타 참조1건, 학습 가능0건이다. 이 수는 모델 성능이나 학습 정답 수가 아니다.

분류표·지침·파일럿 JSON 해시와 비공개 importer 검사는 통과했다. 그러나 원본 commit의 manifest12개 중 `pilot100_review.md` 하나가 불일치한다. Git blob으로 재확인한 실제 SHA256은 `bc6c2ac1766ec977bb7f43a4765622ed388918bc01756a18b7f5efb26ac4e982`, manifest 값은 `d3a2c917ef3fb42236f4ac9b61337ef92aa5b7eb30abc98df3add7edd1ef8e7f`다. 원본 전체 검증은 PASS로 표시하지 않으며 참고 브랜치도 수정하지 않았다.

합성 CPU 학습·모킹 API·입력/집계 회귀137개와 실제 고정 KcELECTRA 원본 해시·safe import·CPU 인코더 실행을 확인했다. 최신 결과는 `VALIDATION.json`에 기록한다. 실제 한국어 정답 정확도·L4 성능·제공자 호출·DB/서비스 연결은 별도 미검증이다. 자세한 준비 절차는 [PREPARATION_KO.md](PREPARATION_KO.md)를 따른다.

## 후속 서비스 계약

현재 웹 분석 후보는 YouTube 영상/댓글용이다. Steam leaf 집계를 그 전체 감성 필드에 넣거나 실제 모델이 연결됐다고 표시하지 않는다. 별도 계약에는 다음을 보존해야 한다.

- 모델·taxonomy·라벨 매핑·입력/전처리·프롬프트·분할·실험 식별자.
- 게임·기간·언어·구매/추천/오프토픽·완전성·as_of와 고유 원본/분석 분모.
- 리뷰 키·수정본·스냅샷·leaf·원래 감성·실제 근거 출처와 조건.
- 성공·실패·보류·모델 빈 예측·사람의 구체 평가 없음·HOLD의 구분.
- 같은 leaf 양극성, 파생 혼합, 상위 고유 리뷰 수; 알 수 없는 수는 null.
- 난도 주관성 문구와 허용/금지 인사이트 계약.

`summarize`는 로컬 집계와 해석 제한 계약이다. 후속 생성 경로는 `assert_insight_claim_allowed`와 같은 제한을 적용하고 동일 스냅샷의 실제 근거를 검증해야 한다. 현재 분류기는 근거 추출기가 아니며 임의 인용문을 만들지 않는다. RAG 검색·답변 생성·프론트 표시의 실제 연결은 남아 있다.

서버 간 자동 전송도 미구현이다. 향후 고정 원본 스냅샷 → outbox → 수신 staging → 해시·건수·버전 검증 → 원자적 공개 포인터 교체로 연결하고, 기존 DB 구조·최소 권한을 읽기 전용으로 확인한 뒤 격리 검증해야 한다. 이 문서는 운영 SQL·권한 변경·배포 승인이 아니다.
